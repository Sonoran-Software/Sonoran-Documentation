## Sonoran CAD, CMS, and Radio Desktop App Updates Failing {#sonoran-cad-cms-and-radio-desktop-app-updates-failing}

On 7/28/2025, we updated our code signing certificate following its scheduled three-year expiration. As a result, automatic updates may fail on older versions of our applications. To restore update functionality, please download and install the latest version. Future updates will then resume automatically.
