## Configuring your Listener {#configuring-your-listener}

### 1. Admin Panel Configuration {#id-1.-admin-panel-configuration}

In the Administrative Panel, navigate to: Advanced > API Integration

Enter your server's public IP address and your game server's port. Sonoran CMS will send events to `http://ip:gameport/sonorancms/events` **utilizing your existing game port**.

## Developer Documentation {#developer-documentation}

Our [integration plugins](/cms/integration-capabilities/in-game-integration-resources) may rely on these push events for full functionality. Interested in developing your own plugins? Expand the push event and API endpoint documentation in the left side drawer.
