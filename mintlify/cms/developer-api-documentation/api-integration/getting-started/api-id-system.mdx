title: API ID System
description: Setting your account's API ID allows your account to be easily used with
  the public API.
---

## Changing Your Global Account's API ID Settings {#changing-your-global-accounts-api-id-settings}

### 1. Navigate to Account Profile {#id-1.-navigate-to-account-profile}

Select `Community Profile` in the dropdown below your username.

![Sonoran CMS - Top Left Drop-Down](https://docs-assets.sonoransoftware.com/sha256/4b/4b6277390b58a559f2ed0024a05ccf0a77c81f6d915bdaef16e313e7150eaab2.png)

### 2. Open API ID Settings {#id-2.-open-api-id-settings}

Click `Settings` under profile view

![Sonoran CMS - Profile View](https://docs-assets.sonoransoftware.com/sha256/75/75db57ecb41fa2c9abc598ce821092dc3131c07dfe6c8584b37c7149db85b267.png)

### 3. Enter API ID Details {#id-3.-enter-api-id-details}

Input the ID you're wanting to save and set the nickname for it

![Sonoran CMS - API ID Settings](https://docs-assets.sonoransoftware.com/sha256/54/549a5c10621f0bf200495a17b398bc0c1b965ce93ba601c095b019a43b479b66.png)

### 4. Add API ID & Save {#id-4.-add-api-id-and-save}

Click the blue "ADD API ID" button and click the green "SAVE API IDS" button at the top to save it in the backend.

![Sonoran CMS - Saving API ID Settings](https://docs-assets.sonoransoftware.com/sha256/b2/b28b6f252b0ebd09e15d1c9a05ac5f09f05d18ef163f9a5f4cccba52150a37f1.png)

## Changing Your Community Account's API ID Settings {#changing-your-community-accounts-api-id-settings}

### 1. Open Settings {#id-1.-open-settings}

From the main Sonoran CMS community Dashboard view, select "Settings" at the bottom of the left menu

![Sonoran CMS - Main Community Dashboard Side Menu](https://docs-assets.sonoransoftware.com/sha256/29/298640e20024daf3b4867e5d74710224bf6b955fdba28c91b1ff87d0bd2fc371.png)

### 2. Select your API ID Preferences {#id-2.-select-your-api-id-preferences}

Select the drop-down for API ID preferences and select your preference

![Sonoran CMS - Community API ID Settings](https://docs-assets.sonoransoftware.com/sha256/ad/ad5c589bb28124c705e775235936ecbfe538c49b383396234ab72368b0d22933.png)

### 3. Add API ID's {#id-3.-add-api-ids}

Depending on your preferences you can add more API IDs that are specifically only on your community account.

![Sonoran CMS - Community API ID Settings](https://docs-assets.sonoransoftware.com/sha256/33/336486099460d37d3491878d44cd21baa7ec971403116295ba292e9bae5d418b.png)
