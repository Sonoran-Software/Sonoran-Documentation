## Set Game Servers {#set-game-servers}

`POST` `https://api.sonorancms.com/servers/set_game_servers`

Set Sonoran CMS community server configurations.

#### Request Body {#request-body}

| Name | Type   | Description                    |
| ---- | ------ | ------------------------------ |
| id   | string | Community ID                   |
| key  | string | API Key                        |
| type | string | GET\_GAM&#x45;_\__&#x53;ERVERS |
| data | array  |                                |

<Tabs>
<Tab title="200: OK ">

```json
{
    "success": true,
    "data": [
        {
            "id": 1,
            "name": "Server 1",
            "description": "Default server description",
            "ip": "0.0.0.0"
            "port": "00000"
        }
    ]
}
```

</Tab>
