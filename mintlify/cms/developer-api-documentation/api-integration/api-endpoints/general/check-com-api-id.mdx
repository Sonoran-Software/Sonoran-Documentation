## Check Com APIID {#check-com-apiid}

`POST` `https://api.sonorancms.com/general/check_com_apiid`

Check if a API ID is attached to any community account

#### Request Body {#request-body}

| Name                                   | Type   | Description                   |
| -------------------------------------- | ------ | ----------------------------- |
| id\*   | string | Community ID                  |
| key\*  | string | API Key                       |
| type\* | string | CHECK\_CO&#x4D;_\__&#x41;PIID |
| data\* | array  | Array of request objects      |

<Tabs>
<Tab title="200: OK ">

```javascript
{{Sonoran CMS Account Username}}
```

</Tab>

<Tab title="400: Bad Request The following 400 errors may be sent in response:">

```javascript

INVALID COMMUNITY ID
API ID NOT LINKED TO AN ACCOUNT IN THIS COMMUNITY
```
