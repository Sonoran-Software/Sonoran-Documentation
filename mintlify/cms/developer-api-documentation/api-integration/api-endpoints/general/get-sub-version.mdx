For more information, see our [pricing ](/cms/pricing/pricing-faq)page.
</Warning>

## Get Sub Version {#get-sub-version}

`POST` `https://api.sonorancms.com/general/get_sub_version`

Get Sonoran CMS subscription version of a community.

#### Request Body {#request-body}

| Name                                   | Type   | Description                   |
| -------------------------------------- | ------ | ----------------------------- |
| id\*   | string | Community ID                  |
| key\*  | string | API Key                       |
| type\* | string | GET\_SU&#x42;_\__&#x56;ERSION |
| data\* | array  | Array of request objects      |

<Tabs>
<Tab title="200: OK ">

```javascript
0 - FREE
1 - STARTER
2 - STANDARD
3 - PLUS
4 - PRO
5 - SONORANONE
```

</Tab>

<Tab title="400: Bad Request The following 400 errors may be sent in response:">

```javascript
INVALID API KEY
INVALID COMMUNITY ID
```

</Tab>
