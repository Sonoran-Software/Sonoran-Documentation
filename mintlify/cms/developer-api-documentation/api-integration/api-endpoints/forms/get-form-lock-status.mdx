## Get Form Lock Status {#get-form-lock-status}

`POST` `https://api.sonorancms.com/forms/get_lock_status`

Get the specific form template lock status

#### Request Body {#request-body}

| Name                                   | Type   | Description              |
| -------------------------------------- | ------ | ------------------------ |
| id\*   | string | Community ID             |
| key\*  | string | API Key                  |
| type\* | string | GET\_FORM\_LOCK\_STATUS  |
| data\* | array  | Array of request objects |

<Tabs>
<Tab title="200: OK The following 200 response texts may be sent in response:">

**Locked**

```javascript
true
```

**Unlocked**

```javascript
false
```

</Tab>

<Tab title="400: Bad Request The following 400 errors may be sent in response:">

```javascript
INVALID API KEY
INVALID COMMUNITY ID
INVALID_TEMPLATE_ID
```

</Tab>

</Tabs>

```json
{
    "id": "YOUR_COMMUNITY_ID",
    "key": "YOUR_API_KEY",
    "type": "GET_FORM_LOCK_STATUS",
    "data": [
        {
            "templateId": 1,
        }
    ]
}
```

### Template ID {#template-id}

The `templateId` number can be taken from the form editor's URL when editing a form template.
