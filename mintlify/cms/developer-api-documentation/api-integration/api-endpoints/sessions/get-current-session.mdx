## Get Current Session {#get-current-session}

`POST` `https://api.sonorancms.com/sessions/get_current`

Get the current session for the specified server ID.

#### Request Body {#request-body}

| Name                                   | Type   | Description              |
| -------------------------------------- | ------ | ------------------------ |
| id\*   | string | Community ID             |
| key\*  | string | API Key                  |
| type\* | string | GET\_CURRENT\_SESSION    |
| data\* | array  | Array of request objects |

<Tabs>
<Tab title="200: OK ">

```json
{
    "id": "UUID_OF_SESSION",
    "sysStatus": true,
    "community": "YOUR_COMMUNITY_ID",
    "serverId": 1,
    "startedBy": "UUID_OF_SESSION_STARTER",
    "startedAt": "TIMESTAMPTZ_STRING",
    "endedBy": null,
    "endedAt": null,
    "cancelledBy": null,
    "stats": {},
    "metadata": {},
}
```

</Tab>

<Tab title="400: Bad Request The following 400 errors may be sent in response:">

```javascript
INVALID API KEY
INVALID COMMUNITY ID
NO_SERVER_ID
INVALID_SERVER
SESSION_ERROR
```

</Tab>
