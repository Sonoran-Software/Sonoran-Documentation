## Get Member Records {#get-member-records}

`POST` `https://api.sonorancms.com/disciplinary/get_member_records`

Get a Sonoran CMS community member's disciplinary records by member search fields.

#### Request Body {#request-body}

| Name                                   | Type   | Description          |
| -------------------------------------- | ------ | -------------------- |
| id\*   | string | Community ID         |
| key\*  | string | API Key              |
| type\* | string | GET\_MEMBER\_RECORDS |
| data\* | object | Object               |

```json
  [
    {
      "id": "123",
      "status": true,
      "accId": "123",
      "source": "user",

      "points": 5,

  ]
```
