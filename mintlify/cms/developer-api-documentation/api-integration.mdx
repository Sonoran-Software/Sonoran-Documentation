## Sonoran JS - NPM Library {#sonoran-js-npm-library}

Sonoran CMS offers a complete Node API library from NPM!

`npm i @sonoransoftware/sonoran.js`

[Learn more about our NPM library](https://www.npmjs.com/package/@sonoransoftware/sonoran.js)!

## How are API calls sent? {#how-are-api-calls-sent}

The v2 API uses standard HTTP methods, bearer authentication, and JSON request bodies where applicable.

## Can I integrate this with my gamemode/framework? {#can-i-integrate-this-with-my-gamemode-framework}

Yes, you can integrate with nearly any gamemode using a language that can send HTTP requests.

We provide several drag-and-drop resources written in JS/TS.
