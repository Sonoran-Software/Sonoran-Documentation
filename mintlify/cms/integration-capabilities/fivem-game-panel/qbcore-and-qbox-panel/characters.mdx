## 1. Manage a Character {#id-1.-manage-a-character}



<img src="https://docs-assets.sonoransoftware.com/sha256/f9/f96f21405180d99e56abcdc773c4c26e63373faffe53c4a41d901f54fccbb2c6.png" alt="" width="375" />



The characters tab allows you to view and edit:

* First Name
* Last Name
* Gender
* DOB
* Nationality
* Phone Number
* Cash Balance
* Bank Balance
* Crypto Balance
* and more!

## 2. Player Inventories {#id-2.-player-inventories}

Select the `Inventory` tab on a character to open a drag-and-drop inventory manager.



<img src="https://docs-assets.sonoransoftware.com/sha256/84/8419fd57fb08fea9be6c9ca1b7c6f6655b416e8a395cb6cb36e30880834b3467.png" alt="" />



## Supported Inventory Scripts {#supported-inventory-scripts}

Currently, Sonoran CMS supports the following QB Core inventory scripts:

* QB (Base) Inventory
* Ox Inventory
* Quasar Inventory
* Project Sloth Inventory
* Origen Inventory
* Core Inventory
* Tgiann Inventory

You can suggest more integrations on our [support portal](https://support.sonoransoftware.com).
