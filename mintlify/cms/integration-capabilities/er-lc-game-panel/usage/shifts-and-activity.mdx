## Timeclock {#timeclock}

Timeclock [shift types are configured in the community customization panel](/cms/tutorials/customization).

### Via In-Game Command {#via-in-game-command}



<Accordion title="Via In-Game Command">



Users can clock in or out of their timeclock by using the `:log` command in-game.

Format: `:log clockin [shift type - optional]`



</Accordion>



### Via Discord Command {#via-discord-command}



<Accordion title="Via Discord Command">



Users can clock in or out of their timeclock by using the `/clickockin <type` and `/clockout` commands in [Discord](/cms/integration-capabilities/discord-bot-integration).



<img src="https://docs-assets.sonoransoftware.com/sha256/7b/7b333c3a485304b7923b53d0caba9d8821646e2717f698bb23a4efbe37ffcd86.png" alt="" />





</Accordion>



### Via CMS {#via-cms}



<Accordion title="Via CMS">



Users can clock in or out of their timeclock by selecting the timer icon at the top of the CMS navigation bar.



<img src="https://docs-assets.sonoransoftware.com/sha256/0d/0d779448700b71fdae1dee8ed47eab755a163cd56c39bb477137b19cebe8e699.png" alt="" />

## Activity Time {#activity-time}

When a user joins the ER:LC game server, an automatic activity timer starts. This timer captures a start and stop time log based on your team. These time logs can be [displayed on a roster](/cms/integration-capabilities/er-lc-game-panel/usage/cms-integrations#roster-activity-time), or be shown in one of the integrations below.

## Discord Activity {#discord-activity}

### Discord Shift Reports {#discord-shift-reports}



<Accordion title="Discord Shift Reports">



When a player exits the ER:LC server, a shift report will automatically be direct messaged to them via Discord.

These notifications can be disabled in the CMS notification settings.



<img src="https://docs-assets.sonoransoftware.com/sha256/99/9921775077b9e015cef7c0182d85d1e51cfec5566b8968fddd1953e826621016.png" alt="" />





</Accordion>



### Discord Activity Review {#discord-activity-review}



<Accordion title="Discord Activity Review">



Users can review their activity logs with the `/activity <type>` Discord command. This allows you to review manual timeclock shifts or automatic activity time logs.



</Accordion>
