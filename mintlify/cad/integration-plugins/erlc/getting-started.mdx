## Linking your ER:LC Server {#linking-your-er-lc-server}

Use this guide to connect an ER:LC private server to Sonoran CAD and confirm that in-game events reach the CAD.

### 1. Create an ER:LC API Key {#id-1.-create-an-er-lc-api-key}

1. In ER:LC, open **Menu** > **Servers** > **Owned Servers** and select your private server. If you haven't purchased the API Pack, open **Upgrade Packs** and buy **API Pack**.
2. Join your private server. Open **Server Info** > **Edit Server Settings** and find **ER:LC API**.
3. Select **Edit** next to **API Key** and copy the key. Keep it private.

### 2. Link ER:LC to Sonoran CAD {#id-2.-link-er-lc-to-sonoran-cad}

1. In CAD, open **Admin** > **Integrations**. If asked to choose a game, select **ER:LC**. Open **Manage ERLC integration**.
2. If no CAD server is configured, select **Add server**, enter a name, and select **Save**.
3. Select **Start Setup**. If asked to choose a server, select the CAD server you want to connect.
4. Paste your key into **ER:LC API Key**. When CAD shows **API key confirmed. You can continue.**, select **Continue**.

### 3. Link ER:LC Event Webhooks to Sonoran CAD {#id-3.-link-er-lc-event-webhooks-to-sonoran-cad}

1. In **Set ER:LC Webhook**, copy the URL shown in CAD: `https://events.sonoransoftware.com/erlc`.
2. In your ER:LC private server, open **Server Info** > **Edit Server Settings** > **ER:LC API**. Select **Edit** next to **Event Log Webhook**, paste the URL, and save.
3. Keep the CAD wizard open. In ER:LC chat, type `;test`. Return to CAD. When it shows **Webhook connected. You can continue.**, select **Continue**.

<img src="https://docs-assets.sonoransoftware.com/sha256/d6/d6cfdc164ebe08d448829935fca2b0e5bc99cb29a24b7e2de351efa04d11196e.png" alt="The CAD webhook step showing Webhook connected and Continue, alongside the in-game setup confirmation" />

If CAD is still waiting, check that you saved the webhook URL on the same ER:LC private server whose API key you entered, then run `;test` again.

## Linking your Roblox Account {#linking-your-roblox-account}

Each player must link their own Roblox account to use in-game integrations. One link also works across Sonoran CAD, CMS, and Radio.

- **In the setup wizard:** If your account isn't linked, select **Link Roblox Account**, sign in to Roblox, and approve the link. Return to CAD and select **Refresh**. Once your account is linked, whether you linked it just now or earlier, select **Continue**, then **Finish Setup**.
- **Outside the wizard:** If you see the **Roblox Account Link Required** banner, select **Link**. After approving the link in Roblox, return to CAD and select **Refresh**. The banner disappears when CAD detects the link.
