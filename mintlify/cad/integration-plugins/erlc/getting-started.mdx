## Linking your ER:LC Server {#linking-your-er-lc-server}

### 1. Create an ER:LC API Key {#id-1.-create-an-er-lc-api-key}



<Accordion title="ER:LC API Key">



ER:LC grants API access as a paid upgrade.

Once in-game, select the **Menu** button at the top right > **Servers** > **Owned Servers** > Select your private server > **Upgrade Packs** > **API Pack**.

Select **Edit Server Settings** > Navigate To **ER:LC API** > Select **Edit** to Copy.

### 2. Link ER:LC to Sonoran CAD {#id-2.-link-er-lc-to-sonoran-cad}



<Accordion title="Linking ER:LC to Sonoran CAD">



1. In the CAD, navigate to **Admin** > **Advanced** > **In-Game Integration**.
2. At the top right, make sure **Game: ER:LC** is selected.
3. Select the **ER:LC** tab and **Start Setup**.
4. Select **Start Setup** and paste your **ER:LC API Key** in.



<img src="https://docs-assets.sonoransoftware.com/sha256/c1/c10e99c303bd99adbbb81ad52a8aec0b33fc326f99e5e39d6567ed1520105213.png" alt="" />





</Accordion>



### 3. Link ER:LC Event Webhooks to Sonoran CAD {#id-3.-link-er-lc-event-webhooks-to-sonoran-cad}



<Accordion title="Link ER:LC Event Webhooks to Sonoran CAD">



ER:LC sends Sonoran CAD events for custom commands like traffic stops and vehicle registrations. Additionally, in-game events for robberies, fires, etc. are also sent.

1. Open the **Server Info**
2. Select **Edit Server Settings**
3. Under **ER:LC API** > **Event Log Webhook** > **Edit**
   1. Paste: `https://events.sonoransoftware.com/erlc`
4. In the in-game chat, enter `;test` to verify.

**Webhook Errors**

The ER:LC API may be experiencing a partial outage—this is common after weekend game updates. If you see a red error when setting the Event Log Webhook, it’s likely due to this issue.

## Linking your Roblox Account {#linking-your-roblox-account}

Players must link their Roblox account to their Sonoran account in order to use in-game integrations.

Once linked, the Sonoran account can be used for ER:LC integrations across Sonoran CAD, CMS, and radio.



<Accordion title="Linking Roblox to Sonoran">



If a user in an ER:LC linked community does not have their Roblox account linked, the **Roblox Account Link Required** banner will display at the top of the screen. Press the red **Link** button to redirect to Roblox and link your account.



<img src="https://docs-assets.sonoransoftware.com/sha256/77/7769b8ee186d2a499e8c77a00137baaf86cefadd2ee3c775ca49087d0cca4ada.png" alt="Roblox Account Link Required banner with Refresh and Link buttons" />



Pressing **Link** will open up a window to login and link with Roblox:



<img src="https://docs-assets.sonoransoftware.com/sha256/b8/b8298060e479b117428dd34a44c3ab0346f680836dbae667d55ad0519d9c0125.png" alt="" />



Once linked, return to the CAD and press **Refresh**. The banner disappears when your linked account is detected.



</Accordion>
