<span id="fivem-cad-v4-resource-available" />

FiveM resource and plugin settings are now managed in the CAD admin panel. Import your existing settings once, then make changes in CAD instead of editing configuration files.

For a new installation, follow the [FiveM installation guide](/cad/integration-plugins/in-game-integration/fivem-installation). No migration is needed.

## Migrate Existing Settings {#migrating-to-fivem-cad-v4}

1. Back up your existing `[sonorancad]` folder. Update to the [latest resource release](https://github.com/Sonoran-Software/SonoranCADFiveM/releases/latest), keeping your existing `config.json`, `configuration` folder, and call-template JSON files in place.
2. Start the updated resource. In CAD, open **Admin > Integrations > Manage FiveM integration** and select the matching **FiveM server**.

<img src="https://docs-assets.sonoransoftware.com/sha256/aa/aa690ff16e7a682933da80bdc88c710d1edce3a6b89c8fe62e762d4170c5b0f0.webp" alt="The FiveM integration panel with the server selector and migration command." />

3. Run this command in your **FiveM server console**:

```text
sonorancad migrate
```

4. Wait for the console to confirm migration succeeded, then restart the resources:

```cfg
exec @sonorancad/sonorancad.cfg
```

5. Click **Refresh** in CAD to load your imported settings. Repeat for each FiveM server.

## Change Settings in CAD {#change-settings-in-cad}

Open **Admin > Integrations > Manage FiveM integration** and select your server. Choose **Core settings** for general resource options, or select a plugin to change its settings.

Changes **save automatically**. Run the restart command above to apply them in game. The banner also lets you copy that command.

<img src="https://docs-assets.sonoransoftware.com/sha256/43/432364fbe84724fb2409c423deff026a0655ed7b7c72d2f4e58e7d5d9652e1a6.webp" alt="Body Camera settings with the plugin list, enable and reset controls, and restart command after an automatic save." />

[Browse the plugin guides](/cad/integration-plugins/in-game-integration/available-plugins) for individual settings.

## If Migration Fails {#cad-fivem-v3-depreciation}

Keep your original configuration files and fix the error shown in the server console before retrying. Retrying checks CAD first and does not overwrite settings already saved there.

If you need help, contact [Sonoran support](https://support.sonoransoftware.com/).
