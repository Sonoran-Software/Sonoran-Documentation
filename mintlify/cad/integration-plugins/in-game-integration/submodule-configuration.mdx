## Install the Resource {#install-the-resource}

[Install the current Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation) and connect your server first.

## Activating a Submodule {#activating-a-submodule}

Open **Admin > Integrations > FiveM**. Select the server you want to change, then open a plugin. Settings belong to the selected server, so check the server selector before editing.

### Configure and enable {#id-1.-configure-and-enable-the-submodule}

Use the toggle beside the plugin title to enable or disable it. Hover over an input for help. Related options appear together, and settings for an unused permission mode or framework stay hidden.

Requirement chips show prerequisite plugins. Select a chip to open that plugin. Enable the prerequisites first: disabling a required plugin also disables plugins that depend on it. Enabling the prerequisite again does not automatically re-enable those plugins.

For FiveM control-number inputs, use the documentation icon inside the input to open the [FiveM controls reference](https://docs.fivem.net/docs/game-references/controls/).

Expand **Language** at the bottom of a plugin to customize in-game text. Keep message substitution tokens intact. Custom Lua permission checks and other function editors are available only in **Developer Mode**.

### Save or reset {#id-2.-rename-and-save}

<span id="rename" />
<span id="save" />

Changes save automatically. The reset icon beside the enable toggle restores and saves that plugin's defaults after confirmation.

### Restart Sonoran CAD {#id-3.-restart-sonoran-cad}

When saved, run this command in your server console to apply the changes:

```cfg
exec @sonorancad/sonorancad.cfg
```

### Existing installations {#existing-installations}

If your resource still uses local configuration files, follow the [migration guide](/cad/integration-plugins/in-game-integration/fivem-installation/fivem-resource-migration-v4) to import them into CAD.

### Separate resources {#separate-resources}

Resources such as Tablet, Station Alert, and Pager have their own setup. Follow their individual guides for settings that are not part of the CAD plugin editor.
