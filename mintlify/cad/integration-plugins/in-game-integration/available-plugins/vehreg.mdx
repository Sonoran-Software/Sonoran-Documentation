## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Vehicle Register (VehReg)**. Enable the plugin with the header toggle and review the settings below. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

<Accordion title="Vehicle registration">

| Setting | What it does |
| --- | --- |
| **Vehicle registration command** | Run /reg from inside a vehicle to register it to your CAD character. |
| **Notification override** | Use a different notification system for this plugin or inherit the resource default. Choices: Use server default, ox_lib, Lation UI, pNotify, Chat. |
| **Default reg expire** | Set the expiration text written to new registrations. Use the date format expected by your CAD record. |
| **Default reg status** | Set the status assigned to new vehicle registrations. |

</Accordion>

<Accordion title="Record fields">

| Setting | What it does |
| --- | --- |
| **Custom data** | Set additional values included when a vehicle is registered. |
| **Vehicle color field** | CAD field that receives the source value for Vehicle color field. Use the field ID from the community’s record template. |
| **License plate field** | CAD field that receives the source value for License plate field. Use the field ID from the community’s record template. |
| **Vehicle type field** | CAD field that receives the source value for Vehicle type field. Use the field ID from the community’s record template. |
| **Vehicle model field** | CAD field that receives the source value for Vehicle model field. Use the field ID from the community’s record template. |
| **Registration status field** | CAD field that receives the source value for Registration status field. Use the field ID from the community’s record template. |
| **Expiration date field** | CAD field that receives the source value for Expiration date field. Use the field ID from the community’s record template. |

</Accordion>

<Accordion title="Language">

Expand **Language** at the bottom of the plugin to edit its in-game messages. Keep substitution tokens such as `%s` or `{0}` intact.

| Setting | What it does |
| --- | --- |
| **Not in veh** | Change the text shown to players for Not in veh. Keep any substitution tokens in the text. |
| **No CAD link** | Change the text shown to players for No CAD link. Keep any substitution tokens in the text. |
| **Plate alr registed** | Change the text shown to players for Plate alr registed. Keep any substitution tokens in the text. |
| **Help msg** | Change the text shown to players for Help msg. Keep any substitution tokens in the text. |
| **No char found** | Change the text shown to players for No char found. Keep any substitution tokens in the text. |
| **Incomplete char data** | Change the text shown to players for Incomplete char data. Keep any substitution tokens in the text. |
| **Success reg** | Change the text shown to players for Success reg. Keep any substitution tokens in the text. |

</Accordion>

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the player has already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.

### Configure Custom Record Fields {#id-4.-configure-custom-record-fields}

If you changed the vehicle registration template, review **Vehicle color field**, **License plate field**, **Vehicle type field**, **Vehicle model field**, **Registration status field**, and **Expiration date field**. Enter the corresponding **Field Mapping ID** from the vehicle registration template. These fields currently use text inputs.

Edit the template itself in **Admin > Records and Codes > Custom Records**. **Custom data** supplies vehicle details for spawn codes that the game cannot identify, such as addon vehicles.

## Commands {#commands}

In-game commands can be used to

* `/reg` Registers the vehicle you are currently sitting inside to your currently selected CAD character
