## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Force Register (ForceReg)**. Enable the plugin with the header toggle, review the settings below, and select **Save configuration**. Restart `sonorancad` to apply the saved settings.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

### (OPTIONAL) Utilize the Tablet's Auto Link {#id-3.-optional-utilize-the-tablets-auto-link}

The [tablet resource](/cad/integration-plugins/in-game-integration/available-plugins/tablet) can be configured to automatically link the user when they login, removing the need for users to manually type this in.

## Configuration {#configuration}

<Accordion title="Account linking">

| Setting | What it does |
| --- | --- |
| **Require link** | Require players to link a CAD account before they can proceed. |
| **Link command** | Run /link to open the CAD account linking window. |
| **Auto open link popup** | Open the link prompt automatically for unlinked players. |
| **Allow popup close when unlinked** | Let players dismiss the linking prompt before they link. |

</Accordion>

<Accordion title="Unlinked players">

| Setting | What it does |
| --- | --- |
| **Unlinked player behavior** | Choose what happens when a player has not linked their CAD account. Choices: Reminder, Freeze player. |
| **Reminder position** | Choose where the linking reminder appears on the screen. Choices: Top, Center. |

</Accordion>

<Accordion title="Linking exceptions">

| Setting | What it does |
| --- | --- |
| **Allow linking exceptions** | Limit linking checks to the configured ACE permissions or jobs. Despite this label, matching players are checked, not exempted, by the current resource. |
| **Match players by** | Choose ACE, QBCore, or ESX to decide which players receive linking checks. Choices: ACE, QBCore, ESX. |
| **Jobs** | Jobs whose players receive linking checks when job filtering is enabled. |

</Accordion>

<Accordion title="Freeze player">

With **Freeze player** selected, unlinked players cannot move until they link. **Auto open link popup** controls automatic opening; **Allow popup close when unlinked** controls whether they can dismiss the prompt.

</Accordion>

<Accordion title="Language">

Expand **Language** at the bottom of the plugin to edit its in-game messages. Keep substitution tokens such as `%s` or `{0}` intact.

| Setting | What it does |
| --- | --- |
| **Link prompt** | Set the message players see when asked to link their CAD account. |
| **Link button text** | Set the label of the button players press to link their CAD account. |
| **Captive message** | Text shown to players for Captive message. Keep any substitution tokens in the text. |
| **Verify message** | Text shown to players for Verify message. Keep any substitution tokens in the text. |
| **Instructional message** | Text shown to players for Instructional message. Keep any substitution tokens in the text. |

</Accordion>

When **Match players by** is **ACE**, edit **ACE permissions** instead of **Jobs**. See [ACE Permissions](#ace-permissions) before enabling this filter.

### ACE Permissions {#ace-permissions}

In the current resource, **Allow linking exceptions** enables a filter for who receives linking checks. Listed players are required to link; they are not exempt. Choose **ACE** under **Match players by**, then set **ACE permissions** to the nodes for those players.

For example, with `forcereg.whitelist` in the list:

```cfg
add_ace group.sonoran_cad_linked forcereg.whitelist allow
```

With this filter off, all players receive linking checks. **Jobs** provides the corresponding filter for QBCore or ESX.

## Modes {#modes}

Set **Unlinked player behavior** to **Reminder** or **Freeze player**. This changes the behavior of the [link menu](/cad/integration-plugins/in-game-integration/available-plugins/forcereg#link-menu) popup.

<Accordion title="Reminder">

With **Reminder** selected, an in-game text message appears at **Reminder position**, informing the user to run the `/link` command to connect to the CAD.

</Accordion>

### Link Menu {#link-menu}

The link menu displays a code and button to link. Selecting the **Link CAD** button will automatically open sonorancad.com/id in an external browser, with the code already entered.

If the user is not yet logged into Sonoran CAD in their browser, they must do so first.

After linking, the user will be automatically joined to the CAD community if not already.

### Event {#event}

This event is sent to the **client** after the check is completed.

```lua
Event: "SonoranCAD::forcereg:PlayerReg"

Parameters:
    identifier: The identifier checked
    exists: true/false, if the identifier is linked to a CAD account
```
