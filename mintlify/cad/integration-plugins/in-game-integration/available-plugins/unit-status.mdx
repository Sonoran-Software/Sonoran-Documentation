## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Unit Status is a built-in integration and is hidden from the CAD plugin list. Its default status commands remain available; there is no separate configuration panel. Configure the CAD unit status codes in **Admin > Customization > Unit Status Codes**.

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the player has already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.

### Setup User Permissions {#id-4.-setup-user-permissions}

With the default permission check, players using the status command need the literal `command.setstatus` [ACE permission](https://forum.cfx.re/t/basic-aces-principals-overview-guide/90917). This is the permission node used by the current resource.

**Example**

`add_ace group.sonoran_cad_units command.setstatus allow`

Add this line to your `config.cfg` for a group containing units who should be able to update their status. Avoid granting `builtin.everyone` unless public access is intentional.

## Commands {#commands}

In-game commands can be used to

* `/setstatus [status]` Set your unit status in the CAD.

## Function {#function}

This is a server-side function only and is exported as `cadSetUnitStatus`. Use `setUnitStatus` if using with other submodules.

```lua
cadSetUnitStatus(<apiId>, <status>, [player])
```

* apiId: The identifier attached to the unit
* status: A status, can be the actual string or a number, based on configuration
* player (optional): server ID of the player, used to send a client event

## Event {#event}

```lua
--[[
    Event Name: SonoranCAD::unitstatus:UpdateStatus
    Arguments:
        statusText: Text or number of the status to set
]]

```
