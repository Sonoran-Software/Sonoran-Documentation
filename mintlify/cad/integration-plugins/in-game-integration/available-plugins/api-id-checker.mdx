---
title: Check Account Link
description: Check whether a FiveM identifier is linked to a CAD account.
---

This check is built into the resource. It has no separate plugin settings in CAD. Players should use `/link` to link their account; the old `/apiid` command is not part of the current resource.

## Usage {#usage}

### Command {#command}

Administrators can run `forcecheck <identifier>` in the server console to print whether the identifier is linked. The command is restricted when invoked by a player.

### Function {#function}

The server export accepts an identifier, an optional identifier type, and an optional callback. It also returns the result directly.

#### Example {#example}

```lua
local linked = exports['sonorancad']:CadIsPlayerLinked('license:YOUR_LICENSE')
print(('Linked to CAD: %s'):format(tostring(linked)))
```

### Event {#event}

From a server script, request a check for the player's server ID. The resource resolves the player's identifier.

#### Example {#example-1}

```lua
TriggerEvent('SonoranCAD::apicheck:CheckPlayerLinked', playerId)

AddEventHandler('SonoranCAD::apicheck:CheckPlayerLinkedResponse', function(player, identifier, exists)
    print(('Player %s linked: %s'):format(player, tostring(exists)))
end)
```
