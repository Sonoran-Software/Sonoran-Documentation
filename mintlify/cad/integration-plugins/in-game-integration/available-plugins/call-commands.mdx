## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).

The [locations submodule](/cad/integration-plugins/in-game-integration/available-plugins/locations) includes required logic to send location data and is **already enabled by default**. Keep this submodule enabled to maintain functionality.

The [postals submodule](/cad/integration-plugins/in-game-integration/available-plugins/postals) is optional and also enabled by default. Keep this submodule enabled if you wish to include postal code information with emergency calls.
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Call Commands**. Enable the plugin with the header toggle, review the settings below, and select **Save configuration**. Restart `sonorancad` to apply the saved settings.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

<Accordion title="Settings">

| Setting | What it does |
| --- | --- |
| **Notification override** | Use a different notification system for this plugin or inherit the resource default. Choices: Use server default, ox_lib, Lation UI, pNotify, Chat. |
| **Call types** | Each entry registers a slash command, such as /911. Players enter the command followed by their call details. |
| **Enable panic** | Let players run /panic in FiveM and allow other resources to trigger the same panic action. |
| **Add panic call** | Create an emergency call when a panic alert returns from CAD. |

</Accordion>

In **Call types**, select a row to edit it or add another call type. Set its command name, emergency-call toggle, chat suggestion, and description prefix. Players run the command followed by their call details.

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the player has already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration's panic feature to work.

## Usage {#usage}

### Commands {#commands}

In-game commands can be used to

* `/panic` Activates your unit's panic status
* `/911` Sends a 911 call to the CAD
* `/511` Sends a 511 call to the CAD (Civil)
* `/311` Sends a non-emergency call to the CAD (Civil)

### Key Binds {#key-binds}

Users can customize a keybind to activate their panic status.

Navigate to **Settings** > **Keybinds** > **FiveM** and look for the **Panic Button** keybind under the resource `sonorancad`.

<img src="https://docs-assets.sonoransoftware.com/sha256/66/661e9d63aced04e17cbc4d5b0c9a719c20b8bbfeae74ae9183a0feb6af4dd6bd.png" alt="" />

### ACE Permissions {#ace-permissions}

The distributed `sonorancad.cfg` grants the panic command node used by the panic keybind:

```cfg
add_ace builtin.everyone command.panic allow
```

`/panic` is currently registered with ACE restriction disabled, so this bundled entry provides compatibility/default access rather than acting as an authorization boundary. The `/911`, `/311`, and `/511` commands are also registered without ACE restriction. Do not replace this line with a group grant expecting `/panic` to become role-restricted; the current source does not enforce `command.panic`.

### Call Location {#call-location}

Calls include the location captured when they are reported. Response waypoints are configured in [Dispatch Notify](/cad/integration-plugins/in-game-integration/available-plugins/dispatch-notify); there is no separate Call Commands location switch in the CAD editor.
