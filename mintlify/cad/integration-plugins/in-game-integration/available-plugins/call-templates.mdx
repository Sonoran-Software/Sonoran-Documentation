## Call Templates {#call-templates}

Create dispatch calls from saved CAD call types using in-game commands.

## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).

The [locations submodule](/cad/integration-plugins/in-game-integration/available-plugins/locations) includes required logic to send location data and is **already enabled by default**. Keep this submodule enabled to maintain functionality.

Enable **Postals** first; the CAD editor requires it before enabling **Call Templates**.
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Call Templates**. Enable the plugin with the header toggle and review the settings below. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the player has already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.

## Configuration {#configuration}

<span id="c.-add-call-type-json-files" />

### Templates {#templates}

1. Fill out a call in the **Dispatch Call Editor**, then click the save icon beside **Saved Types**.
2. In **Call Templates**, select **Add call template**. Choose a **Saved call type**, then select **Add**.
3. Select **Add command** and choose the template it should use. Add the command; it saves automatically.
4. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console, then try the command in-game.

The picker lists saved call types that have not already been added. If it is empty, save a call type in the Dispatch Call Editor first. The selected template is stored with the FiveM configuration; no JSON file needs to be placed on the server. To replace a template after editing its saved call type, remove it and add the updated type again. Removing a template also removes its linked commands after confirmation.

### Commands {#template-commands}

Select a command row to edit it, or use **Add command**. Enter the command name without `/`.

| Setting | What it does |
| --- | --- |
| **Command** | Slash command players will run, such as ts or towreq. |
| **Call template** | Saved call template used by this command. |
| **Suggestion text** | Help shown in chat for the command. |
| **Description prefix** | Text placed before the call description. |
| **Call title** | Optional title used instead of the template title. |
| **Call code** | Optional code used instead of the template code. |
| **Include template description** | Include the description saved in the template. |
| **Include player unit** | Attach the player’s CAD unit to the call. |
| **Include Wraith plate** | Include the locked plate from Wraith when available. |
| **Use ACE permissions** | Require the FiveM command permission described below. |

<Accordion title="Settings">

| Setting | What it does |
| --- | --- |
| **Notification override** | Use a different notification system for this plugin or inherit the resource default. Choices: Use server default, ox_lib, Lation UI, pNotify, Chat. |

</Accordion>

### ACE Permissions {#ace-permissions}

With **Use ACE permissions** enabled, grant `command.<command>` to the appropriate server role. The bundled `/ts` and `/towreq` commands require these permissions:

```cfg
add_ace group.sonoran_cad_dispatch command.ts allow
add_ace group.sonoran_cad_dispatch command.towreq allow
```

Replace the group with your server's dispatch role. Use the configured command name if you rename either command.

## Usage {#usage}

By default, this submodule comes with a `/ts` (traffic stop) and `/towreq` (tow request) commands.

Example:

`/ts Blue four door sedan, occupied x1`

* Creates a dispatch call with the presets for a traffic stop.
* Adds `Blue four door sedan, occupied x1` to the description.
* Pre-fills the call's address and postal location with your in-game location.
