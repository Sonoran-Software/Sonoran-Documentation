## Configuration {#configuration}

Open **Admin > Integrations > FiveM > Framework Support (ESX/QBCore) and Auto Fines** for the selected server. Choose **ESX** under **Framework**, enable the plugin, and select **Save configuration**. Restart `sonorancad` after changes.

The separate ESX Support module has been consolidated into Framework Support. See its [full configuration reference](/cad/integration-plugins/in-game-integration/available-plugins/framework-support-esx-qbcore-and-auto-fines) for the current controls.

## Auto-Fines {#auto-fines}

Enable **Issue fines** and enter eligible record names in **Forms that can issue fines**. The resource reads fine amounts from the record's Charges and Speed sections. Players must link their CAD account.

## Legacy ESX Support {#legacy-esx-support}

Choose **Legacy ESX** only for older ESX installations that store all characters in a separate `characters` table. This mode requires MySQL-Async. It is distinct from the standard **ESX** choice.
