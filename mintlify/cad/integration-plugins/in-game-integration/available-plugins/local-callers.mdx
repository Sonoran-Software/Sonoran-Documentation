## Installation Guide {#installation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).

</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Local Callers**. Enable the plugin with the header toggle and review the settings below. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

### Configuration {#configuration}

Enable **Call Commands** first; the editor requires it for Local Callers.

<Accordion title="Incident calls">

| Setting | What it does |
| --- | --- |
| **Gun sightings** | Allow NPC witnesses to report a visible weapon. |
| **Carjacking** | Allow NPC witnesses to report a vehicle theft. |
| **Death** | Allow NPC witnesses to report a death. |

</Accordion>

<Accordion title="Call timing">

| Setting | What it does |
| --- | --- |
| **Call cool down** | Set the minimum time between NPC calls, in seconds. |
| **Local run time** | Set how long the NPC moves toward the player before making the call, in seconds. |
| **Auto-delete after (minutes)** | Delete calls created by NPCs after this many minutes. Use 0 to keep them. |
| **Gun sighting call (seconds)** | Set how long the caller stays on the line after seeing a gun, in seconds. |
| **Carjacking call (seconds)** | Set how long the caller stays on the line after a carjacking, in seconds. |
| **Death report (seconds)** | Set how long the caller stays on the line after a death, in seconds. |

</Accordion>

<Accordion title="Call areas">

| Setting | What it does |
| --- | --- |
| **Whitelist zones** | Only the listed call types can be reported by NPCs inside each zone. |

</Accordion>

## Usage {#usage}

#### Emergency Calls {#emergency-calls}

When near an AI "local/ped" in-game, they will automatically pull out their phone and begin to place an emergency call if you are spotted committing one of the configured crimes.

#### Emergency Call Information {#emergency-call-information}

While the local caller is placing the emergency call, killing them before the configured timer expires will only send a partial report—making it harder for police to get a full description of you.

Descriptions from the caller are based on clothing items. Use **Male** and **Female** under **Caller details** to describe custom clothing. Use **White list** for clothing or ped combinations that should be ignored.
