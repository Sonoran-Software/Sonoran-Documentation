## Activation Guide {#activation-guide}

Traffic stops are now configured through [Call Templates](/cad/integration-plugins/in-game-integration/available-plugins/call-templates). There is no separate Traffic Stop plugin in the current CAD editor.

Open **Admin > Integrations > FiveM > Call Templates**, select the server, then review the `/ts` command. Choose its **Call template**, optional **Call title** and **Call code**, and whether to **Include player unit** or **Include Wraith plate**. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

## Permissions {#id-4.-enable-user-permissions}

With **Use ACE permissions** enabled, grant access to the appropriate role:

```cfg
add_ace group.sonoran_cad_dispatch command.ts allow
```

Players must [link their CAD account](/cad/integration-plugins/in-game-integration/link-user-in-game) and have an active unit to attach themselves.

## Usage {#usage}

Run `/ts Blue four door sedan, occupied x1` to create the configured traffic-stop call with those details.

## Custom Events {#custom-events}

The old Traffic Stop module's event belongs to that retired module. For current integrations, use the [Call Templates workflow](/cad/integration-plugins/in-game-integration/available-plugins/call-templates) or the supported [server events](/cad/integration-plugins/in-game-integration/framework-development-documentation/server-events).
