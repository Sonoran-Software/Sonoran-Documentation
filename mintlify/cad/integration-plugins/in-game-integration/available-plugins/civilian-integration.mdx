## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

<Info>

This submodule is already **enabled by default** when installing the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).
</Info>

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Civilian Integration**. Enable the plugin with the header toggle, review the settings below, and select **Save configuration**. Restart `sonorancad` to apply the saved settings.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the player has already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.

## Configuration {#configuration}

<Accordion title="In-game commands">

| Setting | What it does |
| --- | --- |
| **Civilian ID command** | Run /civid show to show your ID to nearby players. Enter the base command without the slash. |
| **Notification override** | Use a different notification system for this plugin or inherit the resource default. Choices: Use server default, ox_lib, Lation UI, pNotify, Chat. |

</Accordion>

<Accordion title="Civilian identities">

| Setting | What it does |
| --- | --- |
| **Allow temporary IDs** | Players can use /civid set to create a temporary ID with their own name and date of birth. |

</Accordion>

<Accordion title="ID cards">

| Setting | What it does |
| --- | --- |
| **ID display format** | Choose how nearby players see your ID. Chat uses the selected notification system. Choices: Display card, Chat. |
| **ID display range** | Set how close another player must be to see your ID when you run /civid show, in game units. |

</Accordion>

## Usage {#usage}

#### Commands {#commands}

In-game commands can be used to

* `/civid show` Show the ID of your currently selected character in the CAD to the nearest player.
  * If using the `/civid set` command, it will show your manually configured character info instead of from the CAD.
* `/civid set` Manually enter character information for your ID.
* `/civid reset` Reset the manually entered character information for your ID.
* `/civid refresh` Removes the "cached" characters for the client. This allows players to swap characters in the CAD without relogging or waiting for the cache timer.
* `/civid help` Displays a list of commands.

### Export {#export}

You can use this export to fetch all characters for a specific player ID. This is a server-side export only.

```lua
Function: "GetCharacters"
Parameters:
    player: the player ID
    callback: function to call after fetching the data. Returns an array of character objects.

Example:
    exports["sonorancad"]:GetCharacters(playerId, function(result)
        -- do stuff with result, an array of character objects
    end)
```

This function can also be used in other submodules (without the export bit).
