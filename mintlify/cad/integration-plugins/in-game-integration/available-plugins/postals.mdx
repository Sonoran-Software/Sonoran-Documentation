## Activation Guide {#activation-guide}

### Download and Install the Core {#id-1.-download-and-install-the-core}

If you haven't already, be sure to install and configure the [SonoranCAD Core](/cad/integration-plugins/in-game-integration/fivem-installation) first.

### Activate the Submodule and all Dependencies {#id-2.-activate-the-submodule-and-all-dependencies}

Open **Admin > Integrations > FiveM**, select the server, then open **Postals**. Enable the plugin with the header toggle and review the settings below. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

### Configure Postal Script and Exports {#id-3.-configure-postal-script-and-exports}

Choose **Mode** below, then follow the matching resource, file, or event instructions in [Usage](#usage).

## Configuration {#configuration}

<Accordion title="Postal source">

| Setting | What it does |
| --- | --- |
| **Mode** | Choose whether to get postal coordinates from a resource, a FiveM event, or a file. Choices: Nearest postal resource, Resource event, Custom postal file. |
| **Nearest postal resource name** | Shown for Nearest postal resource. Set the name of the installed resource that supplies nearest postals. |
| **Nearest postal event** | Shown for Resource event. Set the client event this plugin listens to for nearest postal updates. |
| **Custom postal codes file** | Shown for Custom postal file. Set the path to the file that contains custom postal coordinates. |

</Accordion>

<Accordion title="Location updates">

| Setting | What it does |
| --- | --- |
| **Should send postal data** | Send the player’s nearest postal from the game client to the FiveM server. |

</Accordion>

## Usage {#usage}

<Info>

If the configured postal resource or custom postal data is unavailable at runtime, SonoranCAD will now continue sending regular street names and coordinate-based location updates without a postal prefix. Check the troubleshooting error codes `ERR-LOC-104`, `ERR-LOC-105`, and `ERR-LOC-106` if postal data is missing or failing.
</Info>

### Using [Nearest-Postal](https://forum.cfx.re/t/release-nearest-postal-script/293511) {#using-nearest-postal}

<Warning>

The plugin only supports 1.5.0 or higher of the nearest-postal plugin. Be sure to download the latest version before using.
</Warning>

If you're using the publicly available [nearest-postal script](https://forum.cfx.re/t/release-nearest-postal-script/293511), some minor configuration is required.

#### Set the Resource Name {#id-1.-set-the-resource-name}

Set **Mode** to **Nearest postal resource**. Enter the exact installed resource folder name in **Nearest postal resource name**, such as `nearest-postal`. The resource must provide the `getPostal` export; entering an unrelated HUD name will not work.

#### Ensure Proper Startup Order {#id-2.-ensure-proper-startup-order}

Be sure that you are starting the nearest-postals addon/resource **before/above** where you `ensure sonorancad` in your `server.cfg`.

Be sure to restart both the Sonoran CAD resource and the nearest-postal script, or restart your server entirely to apply the changes made.

### Custom Postal Codes File {#custom-postal-codes-file}

Set **Mode** to **Custom postal file**. Place your JSON file in `sonorancad/submodules/postals` and enter its filename, including `.json`, in **Custom postal codes file**. The current resource already includes JSON files in this folder in its manifest.

Each entry needs a postal code and numeric map coordinates:

```json
[{ "code": "100", "x": 123.4, "y": -456.7 }]
```

Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

### Custom Postal Events {#custom-postal-events}

Set **Mode** to **Resource event** and enter the event name in **Nearest postal event**. Your postal resource must trigger that **client-side event** with the player's current postal whenever it changes. For example, if the field is `my_postals:changed`:

```lua
TriggerEvent('my_postals:changed', '100')
```

This mode listens for updates; it does not call an export to request them.

## Troubleshooting {#troubleshooting}

If postal lookup fails, location updates for units will still continue using normal street/location data. Postal-specific failures now surface through the troubleshooting codes below instead of stopping all location updates:

* `ERR-LOC-104`: postal resource unavailable
* `ERR-LOC-105`: configured postal file missing or invalid
* `ERR-LOC-106`: postal lookup failed at runtime

See the [FiveM error codes reference](/cad/integration-plugins/in-game-integration/fivem-installation/troubleshooting/error-codes) for the full descriptions and recommended fixes.

### The configured postals file (postals\_file.json) was not found {#the-configured-postals-file-postals_file.json-was-not-found}

Confirm the JSON file is in `sonorancad/submodules/postals`, its filename matches **Custom postal codes file**, and each entry contains `code`, `x`, and `y`. Use the current resource manifest, which includes `submodules/postals/*.json`, then restart the resource.
