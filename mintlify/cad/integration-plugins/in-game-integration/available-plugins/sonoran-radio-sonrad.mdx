This submodule connects Sonoran CAD to [Sonoran Radio](https://sonoranradio.com/), a separate resource and system.
</Info>

*Sonoran CAD x Sonoran Radio*

## Activation Guide {#activation-guide}

### Download and Install the Resource {#id-1.-download-and-install-the-resource}

If you have not already, install the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).

Then, [enable the `sonrad` plugin](/cad/integration-plugins/in-game-integration/submodule-configuration).

### Adjust the Configuration {#id-2.-adjust-the-configuration}

Open **Admin > Integrations > FiveM**, select the server, then open **Sonoran Radio (sonrad)**. Enable the plugin with the header toggle, review the settings below, and select **Save configuration**. Restart `sonorancad` to apply the saved settings.

See [Submodule Configuration](/cad/integration-plugins/in-game-integration/submodule-configuration) for requirements, reset, and migration details.

<Accordion title="Radio name">

| Setting | What it does |
| --- | --- |
| **Sync radio name** | Update the player’s Sonoran Radio name from their CAD unit information. |
| **Radio name format** | Use &#123;UNIT_NUMBER&#125; for the callsign and &#123;UNIT_NAME&#125; for the unit’s name in Sonoran Radio. |

</Accordion>

### Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the players have already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.
