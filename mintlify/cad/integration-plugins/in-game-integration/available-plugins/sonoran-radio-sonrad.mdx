*Sonoran CAD x Sonoran Radio*



## Activation Guide {#activation-guide}

### 1. Download and Install the Resource {#id-1.-download-and-install-the-resource}

If you have not already, install the [Sonoran CAD FiveM resource](/cad/integration-plugins/in-game-integration/fivem-installation).

Then, [enable the `sonrad` plugin](/cad/integration-plugins/in-game-integration/submodule-configuration).

### 2. Adjust the Configuration {#id-2.-adjust-the-configuration}

The CAD display settings are stored inside of the `/configuration/sonrad_config.lua` file.

### 3. Ensure Players are Linked {#id-3.-ensure-players-are-linked}

Ensure the players have already [linked their CAD](/cad/integration-plugins/in-game-integration/link-user-in-game) for this integration to work.
