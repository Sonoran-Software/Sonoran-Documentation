## B. Pre-Configured Resource Installation  {#pre-configured-resource-installation-recommended}

<iframe src="https://www.youtube-nocookie.com/embed/QimkcbTPl44" title="Video tutorial" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen />

### Download the ZIP {#id-1.-download-the-zip}

Open **Admin > Integrations > FiveM**, select your server, and use **Start Setup** to download the preconfigured resource. Keep the downloaded connection file private because it contains your API key.

For an existing installation, use the [migration instructions](/cad/integration-plugins/in-game-integration/submodule-configuration#existing-installations) before changing plugin settings.

### Extract the ZIP File {#id-2.-extract-the-zip-file}

Extract the `.zip` file into your resources directory. Place the `[sonorancad]` folder directly in the resources root directory.

### Update Your Server Config {#id-3.-update-your-server-config}

In your `server.cfg` file, simply add the following line:

**This is the** 🌟**only**🌟 **line that you need to add to your `server.cfg` file. Do not ensure any other part of the resource.**

```
exec @sonorancad/sonorancad.cfg
```

<Warning>

It is very important that the `sonoran_updatehelper` resource is not started manually. Doing so may cause a server crash if updates are available due to a race condition.

**DO NOT** start the whole \[sonorancad] folder as that will also start the sonoran\_updatehelper which might cause crashing if it is started manually. Example of not what to do `ensure [sonorancad]`
</Warning>

<Accordion title="Advanced - Remove Tablet, pNotify, etc.">

Adding the `exec @sonorancad/sonorancad.cfg` starts multiple resources bundled with the download. If you wish to not use one or more of the resources (or with a different name) you will need to:

* Copy/paste the contents of `sonorancad.cfg` to your `server.cfg`
* Remove the `exec @sonorancad/sonorancad.cfg` line from your `server.cfg`

Do not update the contents of `sonorancad.cfg` as it will be overwritten on resource updates.

</Accordion>

### Configure the Resource {#id-4.-configure-the-resource}

Open **Core settings** for the selected server in **Admin > Integrations > FiveM**. Change the settings below, select **Save configuration**, and restart `sonorancad`.

<Accordion title="Settings">

| Setting | What it does |
| --- | --- |
| **Debug mode** | Write additional troubleshooting details to the FiveM console. |
| **Notification system** | Choose which in-game notification system the resource uses by default. Choices: Automatic, ox_lib, Lation UI, pNotify, Chat. |
| **Allow auto update** | Allow the resource to install updates automatically. |
| **Allow update with players** | Allow the updater to install a release while players are connected. |
| **Update ignore** | List files that the updater should leave in place. |

</Accordion>

With **Notification system** set to **Automatic**, the resource tries ox_lib, Lation UI, pNotify, then Chat. Plugins can select a **Notification override** or inherit this choice.

**Developer Mode** additionally exposes **Mode** (Production or Development), **Push event forwarding URL**, and its **Enable push event forwarding** toggle. These are advanced connection settings.

The resource-root `config.json` is only a connection file. It contains the API key as a string and the server ID as a number; plugin settings belong in CAD:

```json
{ "apiKey": "YOUR_API_KEY", "serverId": 1 }
```

### Configure the Auto-Updater {#id-6.-configure-the-auto-updater}

The Sonoran CAD FiveM resource contains an auto-updater that will override all non-configuration files when a new version of Sonoran CAD is released.

#### Whitelist Specific Files {#whitelist-specific-files}

Use **Core settings > Update ignore** to list the files or directories the updater should preserve, such as custom plate images. Save the configuration and restart the resource.

#### Disable Automatic Updates {#disable-automatic-updates}

Turn off **Allow auto update** in **Core settings**. **Allow update with players** controls whether updates may run while players are connected.

## Additional Configuration {#additional-configuration}

### Convar Overrides {#convar-overrides}

The current resource loads managed settings from CAD. Use **Core settings** and the plugin panels instead of adding old `sonoran_<setting>` overrides to `server.cfg`. Keep only the API key and numeric server ID in the resource-root connection file.

### Manual IP:Port Push Events {#manual-ip-port-push-events}

The resource normally receives CAD events over its websocket connection. To configure the HTTP fallback, open **Admin > Integrations > FiveM > HTTP Events** for the selected server and enter its public IP address and game port (usually `30120`).

To forward events to another service, use **Push event forwarding URL** and **Enable push event forwarding** in **Core settings**, available in **Developer Mode**.

### Steam API Key {#steam-api-key}

<Accordion title="Steam API Key">

If your existing installation uses Steam identifiers for linked players, you'll need to ensure a Steam API key is set in your `server.cfg` file.

You can register a new Steam API Key at [http://steamcommunity.com/dev/apikey](http://steamcommunity.com/dev/apikey)

Then, paste it into your `server.cfg`

```
# Steam Web API key
# If you want to use Steam authentication (https://steamcommunity.com/dev/apikey) # -> replace "" with the key
set steam_webApiKey "YOUR_KEY_HERE"
```

</Accordion>

## Updates {#updates}

Sonoran CAD's integration framework and submodules will automatically update with the latest features, fixes, and changes!

Or, run `sonorancad update` to instantly check and apply any updates for the framework core.

## Commands {#commands}

The Sonoran CAD integration framework comes with several commands. These commands can be run in your server console to provide information, update submodules , and more.

| Command                | Description                              |
| ---------------------- | ---------------------------------------- |
| `sonorancad migrate` | Import an existing local configuration into CAD |
| `sonorancad help`      | Display list of commands                 |
| `sonorancad update`    | Run core/framework updater               |
| `sonorancad debugmode` | Toggle debug mode on/off                 |
| `sonorancad info`      | Dump version info and configuration data |
| `sonorancad support <ID>` | Send diagnostic information using the ID provided by Sonoran support |
| `sonorancad ers`       | Show ERS connection status, callout-list status, and the latest failure |

For ERS issues, start with the [ERS troubleshooting guide](/cad/integration-plugins/in-game-integration/available-plugins/ers#troubleshooting). Support reports include ERS status and failure details automatically.

### Server Crashes {#server-crashes}

1\. Check to make sure `sonoran_updatehelper` or `[sonorancad]` is not being started in your server.cfg.

<Warning>

It is very important that the `sonoran_updatehelper` resource is not started manually. Doing so may cause a server crash if updates are available due to a race condition.

**DO NOT** start the whole \[sonorancad] folder as that will also start the sonoran\_updatehelper which might cause crashing if it is started manually. Example of not what to do `ensure [sonorancad]`
</Warning>

<Info>

We have gotten isolated reports of servers crashing with the following error, this is assumed to be related to having lower end VPS hardware specs and txadmin rebooting the server because the update process is taking too long.
</Info>

![](https://docs-assets.sonoransoftware.com/sha256/e8/e898b873a1033e56188089fa8fc02d36356f0b160b9aab99aa051b6d1c64a60c.png)

### Warning: Could not find file X {#warning-could-not-find-file-x}

1.) Check that the file in question is actually present in the specified file path. To find the correct path please read the example below:

```
Started resource sonorancad (3 warnings)
^3Warning: Could not find file `html/config.js` (defined in fxmanifest.lua:16^7
```

In this example, you would navigate to the `sonorancad` **resource**, open the `html` **folder** and ensure the **file** `config.js` is present.

<Info>

This is simply a **WARNING**, if the resource works **AS EXPECTED**, you can simply ignore the warning and continue
</Info>
