## Install the Resource {#pre-configured-resource-installation-recommended}

### Download {#id-1.-download-the-zip}

Open **Admin > Integrations > FiveM**, select your server, and click **Start Setup**. Download the preconfigured resource.

### Extract {#id-2.-extract-the-zip-file}

Extract the ZIP into your server's `resources` directory. The `[sonorancad]` folder should sit directly inside it.

<img src="https://docs-assets.sonoransoftware.com/sha256/d3/d3d7210ee40bcc6a1d72026954c12bdc99d30e5c4c0bb19c03c23062ff9785d6.png" alt="The sonorancad folder inside the server resources directory." />

### Start the Resource {#id-3.-update-your-server-config}

Add this line to `server.cfg`, then restart your FiveM server:

```cfg
exec @sonorancad/sonorancad.cfg
```

<Warning>
Use this line to start the bundled resources. Do not add `ensure [sonorancad]` or start `sonoran_updatehelper` manually; doing so can cause a crash during updates.
</Warning>

## Manage Settings in CAD {#id-4.-configure-the-resource}

Open **Admin > Integrations > FiveM** and select your server. Use **Core settings** for resource options, or open a plugin to enable it and change its settings.

Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them. You do not need to edit plugin configuration files.

[View plugin settings](/cad/integration-plugins/in-game-integration/submodule-configuration) or [browse the plugin guides](/cad/integration-plugins/in-game-integration/available-plugins).

## Existing Installations {#existing-installations}

If your installation still uses local configuration files, follow the [migration guide](/cad/integration-plugins/in-game-integration/fivem-installation/fivem-resource-migration-v4) to import them into CAD.
