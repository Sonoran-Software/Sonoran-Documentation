## Updating settings

Update the FiveM resource before using new settings. Open the plugin for the correct server in **Admin > Integrations > FiveM** and review the new fields. Changes save automatically. When saved, run `exec @sonorancad/sonorancad.cfg` in your server console to apply them.

The reset icon restores and saves a plugin’s defaults after confirmation. For an installation still using local configuration files, follow [the migration guide](/cad/integration-plugins/in-game-integration/fivem-installation/fivem-resource-migration-v4).
