## Updating settings

Update the FiveM resource before using new settings. Open the plugin for the correct server in **Admin > Integrations > FiveM**, review the new fields, and select **Save configuration**. Restart `sonorancad` to apply them.

The reset icon restores a plugin’s defaults after confirmation. Review the resulting settings before saving. For an installation still using Lua configuration files, follow [the migration workflow](/cad/integration-plugins/in-game-integration/submodule-configuration#existing-installations).
