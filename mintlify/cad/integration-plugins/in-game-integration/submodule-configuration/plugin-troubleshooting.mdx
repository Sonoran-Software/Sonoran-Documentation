## Check the selected server

Open **Admin > Integrations > FiveM**, select the affected server, and confirm the plugin is enabled. Resolve disabled requirements shown beside the plugin description, then enable the dependent plugin again.

## Apply changes

Select **Save configuration**, then restart `sonorancad`. Confirm the resource is connected to the same community and server you edited. If an import failed, preserve the legacy files and resolve the migration error first.

## Collect diagnostic details

Use **Core settings > Debug mode**, reproduce the issue, and review the server console and player F8 console. Follow the [FiveM troubleshooting guide](/cad/integration-plugins/in-game-integration/fivem-installation/troubleshooting) and [error-code reference](/cad/integration-plugins/in-game-integration/fivem-installation/troubleshooting/error-codes).
