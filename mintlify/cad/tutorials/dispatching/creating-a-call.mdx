## Creating a Call {#creating-a-call}



<Accordion title="Add Available Units">



**Manually Add Unit**

To add a unit to your call editor, click on an available unit or unit group, and select "Add to Call"

![Sonoran CAD - Add Unit to Call](https://docs-assets.sonoransoftware.com/sha256/27/27dfd9dde01619a84dd7d08caa50237affbe1a342a619b62dcfd85d78f5c930d.png)

**Attach Nearest Units**

When emergency calls are sent from in-game, they contain a coordinate location. Importing the emergency call from the table or live map will display an option to select and attach the closest units.

Entering a postal code will work as a secondary option to find the nearest units. You must have the [postals submodule](/cad/integration-plugins/in-game-integration/available-plugins/postals) enabled.



<img src="https://docs-assets.sonoransoftware.com/sha256/00/00895ce96c50600192e84c23046834231c80b14588b90025e595fbcbbce5ff84.gif" alt="" width="375" />

*Dispatch Editor: Nearest Units*

 

<img src="https://docs-assets.sonoransoftware.com/sha256/17/17864a8b29fa0abd93b07aded6bdf73cc346ee1acc631a2e4c6b2568b46a0c01.gif" alt="" width="375" />

*Dispatch Editor: Nearest Postal Units*



**Drag-and-Drop**

Drag-and-drop is another fast way to add a unit to an existing call:

![Sonoran CAD - Attach Unit to Existing Call](https://docs-assets.sonoransoftware.com/sha256/33/3343711ecaf248db2fd4a8d24b2aaefac2aaee90bd5e8af9f53a83c633e42c49.gif)

You can also easily detach units from an existing call, or drag a unit from one call to another:

![Sonoran CAD - Existing Call Detach and Switch](https://docs-assets.sonoransoftware.com/sha256/c8/c8af1d0f605698477f93f9bc01e1f1fb537920fad00fe3439a712af0e3e3f5f7.gif)



</Accordion>





<Accordion title="Insert Call Information">



In the call editor, you can view attached units and fill out the call information.\
Once completed, select "Create Call" to initiate the new dispatch call.

![Sonoran CAD - Unit Editor](https://docs-assets.sonoransoftware.com/sha256/20/20ba194368d8ab56ec01dad92b2070698a65aaa39efc0ed4fe5dce1ba1f5934a.png)



</Accordion>

## Manage a Call {#manage-a-call}



<Accordion title="Import Emergency Call">



Emergency calls can be imported directly to the call editor for faster transfer of information. Click on the call to select `Open In Call Editor` to import the call description, address, and more.



<img src="https://docs-assets.sonoransoftware.com/sha256/53/5386977778f26a594f80d19c176f44b1492cb4585a49ba58b4a70b0e365ce575.gif" alt="" width="300" />

*Sonoran CAD: Import Emergency Call*





</Accordion>





<Accordion title="Merge Additional Emergency Call">



Often times civilians will continue to make additional emergency calls with updated information. At any time, you can merge these additional emergency calls into ongoing dispatch calls. Click on the emergency call to `Merge Emergency Call` to your dispatch call editor.

This will append the latest emergency call information to the description and update any address, postal, etc. information.



<img src="https://docs-assets.sonoransoftware.com/sha256/95/956a39e4e9cee4bddb2c19d9fef94bda04dd09c2c8c29c48dcb533340a6cfaee.gif" alt="" width="375" />

*Sonoran CAD: Merge Emergency Call*





</Accordion>





<Accordion title="Track, Update, and Manage the Call">



The new dispatch will be displayed in your "Active Calls" window.\
You can select this call at anytime to preview, edit, or close.\
You can also drag-and-drop the call ID to the call editor to open the call.

![Sonoran CAD - Active Calls](https://docs-assets.sonoransoftware.com/sha256/7f/7f68034e310016bcb9d0d7617ac014a3bf4bbadeab13f91f4254347991b10ce5.png)



</Accordion>





<Accordion title="Call Notes">



Notes can be sent by units attached to the call.

**Text Notes**

Text based notes can be added in the note box and sent by pressing `enter` or `add note`.

**Note Links**

Record links for characters, arrest reports, etc. can also be sent in the dispatch call notes section. [Copy a record link](/cad/tutorials/records-management/searching-for-records#copy-record-links), then press the `Paste` button in the call notes section.



<img src="https://docs-assets.sonoransoftware.com/sha256/3e/3e331773cb2984d2a76726cda0a05312b32b3d65ff23dab640e7e1e950dfde5f.png" alt="" />

*Sonoran CAD - Dispatch Call Notes*





</Accordion>





<Accordion title="Close the Call">



To close the active dispatch, click on the active call and press "Close Call".

Or, you can select "Edit Call", change the status to "Closed", and press "Update Call".

![Sonoran CAD - Close Call](https://docs-assets.sonoransoftware.com/sha256/1f/1fc6b1e08788c1f661d0533208196803a1f95e5cd1f5fd15e9218ceb70652e89.png)



</Accordion>

## Saved Call Types {#saved-call-types}



<Accordion title="Create a Saved Call Type">



Saved call types allow dispatchers to quickly create commonly used calls.

To add a new saved call type, simply fill the information out in your editor, and press the save button. The saved types are organized based off of the call's title.

Saving a call with an identical title as another one will override it.

![Saved Dispatch Calls - Create](https://docs-assets.sonoransoftware.com/sha256/76/7602c8d2549b8d9855d415522faba9330482109409196ea2caac26da4d595c5f.png)



</Accordion>





<Accordion title="Open a Saved Call Type">



To open a saved call type, simply select it from the dropdown at the top of the editor. The dropdown will also automatically filter as you type.

![Saved Dispatch Calls - Select](https://docs-assets.sonoransoftware.com/sha256/05/051afefe05ede9001473cf913181be0bca42f6e23659e22042d8cb5eb240d04a.png)



</Accordion>





<Accordion title="Remove a Saved Call Type">



To remove a saved call type, simply select it from the dropdown and press the trash icon.

![Saved Dispatch Calls - Remove](https://docs-assets.sonoransoftware.com/sha256/95/95b4b274f65e8f8dd89651c783f1e10f766dfc627a079de4397ac968f81c7587.png)



</Accordion>





<Accordion title="Import/Export Saved Call Types">



With a saved call type selected, the export button will allow you to save the current call type to a JSON file. Or, right-click the export button to export all of your saved call tyles to a JSON file.



<img src="https://docs-assets.sonoransoftware.com/sha256/9e/9e0031b12285043076baa40c6c8e953962ead6dcb9598ede317b2741e816ca47.png" alt="" />



To import saved call types, the import button will appear when no saved call is selected. Click the icon to import a JSON file with one or more saved call types.



<img src="https://docs-assets.sonoransoftware.com/sha256/c0/c07fd95865f3f556a4ee5116cb2e559750a670b916197df59087c8400b8e4bed.png" alt="" />





</Accordion>
