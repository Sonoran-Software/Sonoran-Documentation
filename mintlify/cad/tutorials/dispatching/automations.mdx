To update record fields based on saved values, see [Record Automations](/cad/tutorials/customization/record-automations) in Administration. This page covers dispatch unit statuses and timers.

## Dispatch Automations Menu {#dispatch-automations-menu}

The **Automations** menu is available to dispatchers in the call editor.

### Call Attachment: Auto Status {#call-attachment-auto-status}

Automatically change the status of a unit when they're attached and detached to a call, or when their call is closed.



<img src="https://docs-assets.sonoransoftware.com/sha256/43/43fdf3d796d2558f448e0b2c3a8d41b76ba30637b9e2f87cdbfe37f828d23c1f.png" alt="" width="277" />



### Unit Status: Timers {#unit-status-timers}

Automatically start a countdown/up [timer](/cad/tutorials/dispatching/timers) when a unit status is changed. This can be helpful to quickly see how long a unit has been at a particular status, or to be notified once a unit status has been set for too long.
