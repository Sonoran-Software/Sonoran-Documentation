<Accordion title="Unit Groups">



Unit groups are a way to combine two units together, typically when they're in the save vehicle or apparatus.

To add a unit to a group, simply select the unit and select **Add to Group > New Group** or an existing group.

Or, drag-and-drop a unit to an existing group to attach.



<img src="https://docs-assets.sonoransoftware.com/sha256/bf/bf7abee6a71a4d5d066e5faa86ecf254a142d433898192765c3d7461b616fab9.png" alt="" />





</Accordion>





<Accordion title="Persistent Unit Groups">



Unit groups can be configured as **persistent**, meaning they remain visible even when no units are assigned.

Persistent groups are set up in the Department Editor under **Admin → Customization → Departments**. These groups can optionally enforce a maximum number of units that may be attached.



<img src="https://docs-assets.sonoransoftware.com/sha256/61/6198fd5c9e3f17992204906c5a22ea0d01286d92b066625b1028908ea83c6289.png" alt="" />



Once configured, persistent groups can be dragged into the Call Editor or onto an existing dispatch call to attach them.



<img src="https://docs-assets.sonoransoftware.com/sha256/36/36a78d28ebd608e8daef91c3bf622e8bfe8b4236d8b3b0e4e2503775461f1712.png" alt="" />



Units can self-attach to these groups by clicking on their unit number to open the identifier editor **→ Persistent Group**



<img src="https://docs-assets.sonoransoftware.com/sha256/2e/2ea0d125cda0e0cfe473ee60cec3226eade9ccf0d86058803812b3bce7836c73.png" alt="" />





</Accordion>





<Accordion title="Automatic Unit Status">



Dispatchers can also customize what to automatically set unit statuses to after specific actions. Select the [**Automations**](/cad/tutorials/dispatching/automations) button in the call editor to enable status changes on call attachment, detachment, and closure.
