## What are Dispatch Timers? {#what-are-dispatch-timers}

Sonoran CAD allows users to create custom dispatch timers. Some example use cases of these timers are as follows:

* Creating a 10 minute pursuit timer before authorizing a pit maneuver
* Reminders to periodically check in on a unit
* Reminders to check in on a specific dispatch call

When a timer has completed, it will flash an icon next to any [attachments ](/cad/tutorials/dispatching/timers#timer-attachments)and play a [customizable tone](/cad/tutorials/customization/custom-audio-notifications).

## Creating a New Timer {#creating-a-new-timer}

Dispatch timers can be created through multiple different shortcuts.

### Via the Timer Panel {#via-the-timer-panel}

From the start menu: `Unit Management` > `Timers`

Press `New` to create a new timer.

![Sonoran CAD - Timer Panel](https://docs-assets.sonoransoftware.com/sha256/d4/d4dfe38ab4b21704bd38af2e68bd76a0c6368ae28aba184cf7ac39a107d62c18.png)

### Drag-And-Drop to Tab {#drag-and-drop-to-tab}

If you have the timer [panel tab minimized or pinned](/cad/tutorials/customization/customizing-your-layout#7.-tab-system), you can drag a unit, group, or dispatch call right to the tab.

![Sonoran CAD - Drag Unit to Timer Tab](https://docs-assets.sonoransoftware.com/sha256/ab/ab0ad2d80f74f45f6710ccf2e516a27df81e29bf5b4df94ffbb0273369d70c74.gif)

### From the Context Menu {#from-the-context-menu}

Left click on a unit ID, group name, or dispatch call ID: `Timers` > `New Timer`

![Sonoran CAD - New Timer from Context Menu](https://docs-assets.sonoransoftware.com/sha256/a9/a9d198cc5dca2336ff08225c82bd90dfb6f899da479eb434df93edc18d5e5f48.gif)

## Editing a Timer {#editing-a-timer}

### Via Timer Panel {#via-timer-panel}

The timer panel has options to start, pause, restart, and remove a timer.

Additionally, you can expand the timer to change the name and duration.

![Sonoran CAD - Timer Panel](https://docs-assets.sonoransoftware.com/sha256/cf/cf0144418ac0a6849046c6aca85a9db79969d0d254b8e93758b9697c0bb8c385.png)

### Via the Context Menu {#via-the-context-menu}

When a unit, group, or call is [attached to a timer](/cad/tutorials/dispatching/timers#undefined) you can click on the timer icon. A timer menu will be displayed, allowing you to start, pause, restart, or clear the timer's attachment.

![Sonoran CAD - Timer Context Menu](https://docs-assets.sonoransoftware.com/sha256/65/65f710820994738df4e2c73be7c312ceff51b581bdea05cda3525dad1afd22a0.png)

## Timer Attachments {#timer-attachments}

You can attach a unit, group, or call to a timer. This will display a timer icon next to the attached unit or call. You can hover over this icon to view the remaining time, or click on it for the timer context menu.

### Via Drag-And-Drop {#via-drag-and-drop}

In addition to dragging a unit, group, or dispatch call to a minimized tab you can also drag it to a timer in the panel.

![Sonoran CAD - Drag Unit to Timer Panel](https://docs-assets.sonoransoftware.com/sha256/f9/f9f6f4694edd65d2174e3b117baab6ae981e49976db79bee375fb0228e3fb8f7.gif)

### Via Context Menu {#via-context-menu}

Click on a unit, group, or dispatch call: `Timers` > `Select a Timer`

![Sonoran CAD - Attach to Timer from Context Menu](https://docs-assets.sonoransoftware.com/sha256/20/2048d9f79aa2f51f33c284062a44bf2f5c2775f20fec4dc3260420cb8c730cbe.png)
