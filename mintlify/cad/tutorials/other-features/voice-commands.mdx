---
title: Voice Commands
description: Sonoran CAD’s voice commands allow for quick and easy to use actions
  via voice.
---

<Warning>

Currently, Sonoran CAD only supports voice commands in the **Chrome desktop browser**.

Voice recognition is provided by Google, and performance may vary based upon pronunciation, speed, and other factors.
</Warning>

### 1. Enable Microphone Access {#id-1.-enable-microphone-access}

When navigating to a page with voice commands enabled, the browser will prompt you for microphone access.

![Enable microphone access](https://docs-assets.sonoransoftware.com/sha256/24/24d4df413d158b41385c9a25459bdede9cf45060550cab8e7a66c4efe07b7fd8.png)

### 2. Ensure Your Microphone is being Received {#id-2.-ensure-your-microphone-is-being-received}

Now that microphone access has been granted, a red circle will appear at the top right of the browser tab.

![A red, blinking light appears in the browser tab](https://docs-assets.sonoransoftware.com/sha256/4b/4bcb9c80d49b68a11c5d0c75191cd6f0500b42ff6623ff0e5021c67cfb72d479.png)

### 3. Test out the Voice Commands {#id-3.-test-out-the-voice-commands}

Your keyword can be changed from "Sonoran" to something customizable. For more information, check out our guide on [custom voice command keywords](/cad/tutorials/customization/community-branding-and-info).

#### PANIC {#panic}

```
Sonoran, Panic
```

#### Lookup Name {#lookup-name}

```
Sonoran, lookup name John Doe
```

#### Lookup Plate {#lookup-plate}

```
Sonoran, lookup plate ABCD1234
```
