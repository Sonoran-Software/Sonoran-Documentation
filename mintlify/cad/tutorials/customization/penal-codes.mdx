## What are penal codes? {#what-are-penal-codes}



<Accordion title="Penal Codes Explained">



Penal codes can easily be referenced and cited in records/reports as charges.

![Sonoran CAD - Penal Code Reference Window](https://docs-assets.sonoransoftware.com/sha256/87/8727dc7f03faca40e7c901242d9b79a6b1721980c228b78656ac2686117caafe.png)

![Sonoran CAD - Charges Section](https://docs-assets.sonoransoftware.com/sha256/13/13d18ac67000708209ca0aa5c185c80f37ef7cdf8a2fedc06a93a346e79c324f.png)

### 1. Charge Types {#id-1.-charge-types}

You can create your own "Charge Type" options for penal codes. If your country does not have "felonies" you can edit or remove this option.

You can also use the "Auto Sort" feature to quickly format the order of these charge types.

Be sure to hit "Save" before exiting the page.

![Sonoran CAD - Custom Charge Types](https://docs-assets.sonoransoftware.com/sha256/3c/3c42259d58389751a99e0c4e73dd6a9803f934d41c0143c00f0bf2111740403a.png)

### 2. Bond Types {#id-2.-bond-types}

You can create your own "Bond'/Bail Type" options for penal codes. Again, if your country does not use these, you can edit or remove them as needed.

You can also use the "Auto Sort" feature to quickly format the order of these charge types.

![Sonoran CAD - Custom Bond & Bail Types](https://docs-assets.sonoransoftware.com/sha256/84/849578b263a08ec03db1783da5282780a5d005b52c0639e5196831301faa7b5c.png)

### 3. Penal Codes {#id-3.-penal-codes}

Adding, editing, or removing a penal code is easy. Simply click on the existing code to edit it, or press "New Penal Code" to create a new one.

![Sonoran CAD - Penal Code Management](https://docs-assets.sonoransoftware.com/sha256/cf/cf3627f57020c750f081e4c336e6789ed3ba16608edfd0f69a065277d4165774.png)

![Sonoran CAD - Penal Code Editor](https://docs-assets.sonoransoftware.com/sha256/c3/c3ca9e4b86785d9f309a49b7d66c6a91a739b8e89c99eaf3773e2403dd08f88f.png)

### 4. My locality doesn't call them "Penal Codes" {#id-4.-my-locality-doesnt-call-them-penal-codes}

Sonoran CAD allows you to change the naming of "Penal Codes" to anything else you'd like.\
Learn more about our [geographical customization](/cad/tutorials/customization/geographical-settings).



</Accordion>

## Import from Customized Spreadsheet (CSV) {#import-from-customized-spreadsheet-csv}



<Accordion title="Custom Spreadsheet Import">



Sonoran CAD allows you to easily import your penal codes from a spreadsheet (.CSV) file.

<Warning>

**Spreadsheet (CSV) importing is only supported directly from Google sheets.**

Support will not be provided to users modifying their spreadsheets with Excel, or any other program. The official Google sheet includes specific safety checks preventing invalid formats, blank spaces, etc.
</Warning>

### 1. Copy the Google Sheet {#id-1.-copy-the-google-sheet}

Navigate to our [official penal code Google sheet](https://docs.google.com/spreadsheets/d/1Hcm0gHPq8nZx8aPetDRiQXgeAoQMz3CYk2ouwyabmOc/copy) and make a copy. Using a copy of our official sheet ensures your penal codes are formatted correctly.

**You may ONLY use the Google sheet directly. Editing this via Excel or any other program is NOT supported.**

![Penal Codes - Copy Sheet](https://docs-assets.sonoransoftware.com/sha256/94/943c9ab3e5a758c5e36c5c6255e71eb109be8621f54bd06a25913a4dd7f02d2a.png)

### 2. Add Your Penal Codes {#id-2.-add-your-penal-codes}

Now that you have copied this sheet into your Google Drive, you can add new rows and format your penal codes.

<Warning>

**Do NOT modify the very first row.** These names must remain the same to properly format the penal code structure.

Additionally, the `bondAmount` column must be kept as a number.\
All other columns must be formatted as text.
</Warning>

![](https://docs-assets.sonoransoftware.com/sha256/d7/d7d0d802061d40fa3ade5535b3116911237769abfe8f0ef83c607e066f1350b7.png)

### 3. Download the CSV {#id-3.-download-the-csv}

In Google Sheets, navigate to File > Download > Comma Separated Values (.csv) to download the file.

![Google Sheets - Download CSV](https://docs-assets.sonoransoftware.com/sha256/31/3130cce0e14d8cfa98ead8132114038a0ef75b5a8e175284a68c24636559f4a2.png)

### 4. Import the CSV File {#id-4.-import-the-csv-file}

In Sonoran CAD, navigate to Admin > Customization > Penal Codes

In the penal codes section, select the "Import" button.\
Then, select "CSV" as the import type and select your downloaded CSV file.

![Sonoran CAD - Import Data](https://docs-assets.sonoransoftware.com/sha256/58/58d02097399267682ee7de0b960955ac3b5105fd2f9ac262180c87c7ce7e6f17.png)

![File Selector - Select File](https://docs-assets.sonoransoftware.com/sha256/66/660f86798dc59b2cc945d8a9c5610a5a7e37567d5bf32071a3d57c0c673096e0.png)

After selecting the CSV file, your penal codes will be imported into the CAD and saved automatically.



</Accordion>





<Accordion title="Troubleshooting">



Having issues importing your CSV? [Be sure you are using and editing our Google Sheet with the Google Sheets program only](/cad/tutorials/customization/penal-codes#1-copy-the-google-sheet).

Our Google sheet includes specific error checking and validation to handle common mistakes.\
**Support is not provided if you are using Excel, or any other program.**



</Accordion>



## Import from JSON {#import-from-json}



<Accordion title="JSON Import">



You can also build and format your penal codes directly into JSON. These JSON formatted penal codes can be sent via our [API endpoint](/cad/api-integration/api-endpoints/general/set-penal-codes), or pasted directly into the UI for a more user-friendly experience.

### 1. Format the JSON Structure {#id-1.-format-the-json-structure}

The JSON structure is an object array. Be sure to strictly follow the format. All keys are strings, with the exception of `bondAmount` being a number.

```javascript
[
        {
            "code": "(2)06",
            "type": "Felony",
            "title": "Armed Robbery",
            "bondType": "Federal Bail Bond",
            "jailTime": "5-10 Years",
            "bondAmount": 20000
        },
        {
            "code": "(2)07",
            "type": "Felony",
            "title": "Murder",
            "bondType": "Federal Bail Bond",
            "jailTime": "5-50 Years",
            "bondAmount": 100000
        }
    ]
```

### 2. Import the JSON Structure {#id-2.-import-the-json-structure}

In Sonoran CAD, navigate to Admin > Customization > Penal Codes

In the penal codes section, select the "Import" button.\
Then, select "JSON" and paste the JSON object array of penal codes.

![Sonoran CAD - Import Data](https://docs-assets.sonoransoftware.com/sha256/58/58d02097399267682ee7de0b960955ac3b5105fd2f9ac262180c87c7ce7e6f17.png)

![Sonoran CAD - Paste JSON Content](https://docs-assets.sonoransoftware.com/sha256/59/59dcbe002e2d1ea973708e92087908d654852704c2c6d5860946aaa559cb1de2.png)

After pasting the JSON content, your penal codes will be imported into the CAD and saved automatically.



</Accordion>
