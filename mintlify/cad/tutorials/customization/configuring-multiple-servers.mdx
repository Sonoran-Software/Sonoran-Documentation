---
title: Configuring Multiple Servers
description: Sonoran CAD allows you to configure servers to separate units and dispatchers,
  but still share all records globally.
---

<Info>

The free version of Sonoran CAD is limited to one (1) server.\
For more information, see our [pricing](/cad/pricing/faq) or view how to check your community [limits](/cad/tutorials/getting-started/view-your-limits).
</Info>

### Configuring An Additional Server {#configuring-an-additional-server}

In the Admin Customization menu, expand the "Servers" section to add, edit, or remove additional servers in your CAD.

![Additional servers are configured in the customization menu](https://docs-assets.sonoransoftware.com/sha256/a1/a10172e75f3d9b538971b1fbf96f5c5eb5dad86c9837c901d985e196388533c9.png)

### Changing Servers in the CAD {#changing-servers-in-the-cad}

#### Civilian Page {#civilian-page}

In the civilian page, the top right header allows users to swap back and forth between servers.

![Users can select their server in the top header](https://docs-assets.sonoransoftware.com/sha256/d7/d75fa85117cda678d7e139746d7fc611bf739a66b80e8ba80bc9ff4c19ae9ba5.png)

#### Emergency Pages {#emergency-pages}

In the police, fire, EMS, and dispatch pages; users can select their server by clicking on the start menu.

![Emergency Pages - Server Selector](https://docs-assets.sonoransoftware.com/sha256/3e/3e60c051049a0fc8e5454b30910e26f3ebede85d857a842e7519483ed25c2edf.png)
