## Getting Started {#getting-started}

From the start menu select `Record Management` > `Lookup` to open a new lookup window.\
You can also [minimize and pin this window type](/cad/tutorials/customization/customizing-your-layout#7-tab-system) to your taskbar for faster access.

![Sonoran CAD - New Lookup](https://docs-assets.sonoransoftware.com/sha256/7e/7e0ee567abfc60746afa4aa02f05b224e7d0974f951bb63b01534611c549de12.png)

## Running a Search {#running-a-search}

The lookup window has tabs at the top to search via name, license plate, unit identifier, record ID, or one of your [custom lookup types](/cad/tutorials/customization/custom-search-types).

### Partial vs Exact Lookups {#partial-vs-exact-lookups}

The lookup window allows you to toggle the search to return only exact matches, or partial matches.

#### Example: Partial Search {#example-partial-search}

Running partial lookup on `John Anderson` will return results for `John Anderson` and `John Handerson`.

Running an exact lookup on `John Anderson` will only return results for `John Anderson` as `Handerson` is not an exact last name match.

### Record Type Filters {#record-type-filters}

Click on the filter button just above the results tab to expand the filters section.

Here, you can toggle on/off exactly what record types to search for.

![](https://docs-assets.sonoransoftware.com/sha256/f7/f7cfdf055548ae2ee1fc0a1391b2bc64cfef5d8d3bd0de5eb35206cffe683cfa.png)

### Send Lookup to Units {#send-lookup-to-units}

Anyone on the Dispatcher page, or in self-dispatch mode has the option to send the lookup results to other units. Performing this action will have all record results sent to their CAD.

#### Shortcut and Drag-and-Drop {#shortcut-and-drag-and-drop}

You can click on any active unit and select `Lookup` to open a new lookup window with this unit added, or have it added to any existing lookup windows.

Additionally, units and unit groups can be dragged-and-dropped directly to the lookup window.

![Sonoran CAD - Send Lookup to Unit(s)](https://docs-assets.sonoransoftware.com/sha256/a8/a8d4ae2e3dad63da42fc9d54be1bfbc3f8ee3042e3031e1c65900e59a60609e7.gif)

#### Manual Search and Selection {#manual-search-and-selection}

Next to the search button, you can click on the `Send to Unit(s)` button to toggle this mode on.

Using the dropdown, you can type to filter active units or select them from the list directly.

![Sonoran CAD - Send Lookup to Unit(s)](https://docs-assets.sonoransoftware.com/sha256/df/df81ca73d7ef006479cf1d6fb32b8215936109febfd5cbbdf82784410fe132d7.gif)

### Copy Record Links {#copy-record-links}

Records can be [linked to other records](/cad/tutorials/customization/creating-custom-record-and-report-types#linked-records) via the `Linked Records` custom section, or [added to dispatch call notes](/cad/tutorials/dispatching/creating-a-call#note-links).

Press the link icon in the top left to copy the record to your clipboard.

### Lookup from Plate Lock {#lookup-from-plate-lock}

Our [Wraith radar plugin](/cad/integration-plugins/in-game-integration/available-plugins/wraithv2) allows you to lock your plate reader in-game and have the lookup automatically ran in your CAD.

### Voice Commands {#voice-commands}

Lookups can also be ran via a search [voice command](/cad/tutorials/other-features/voice-commands).
