## Adding the Diagram Builder {#adding-the-diagram-builder}

The scene diagram builder allows you to create detailed visuals of vehicle accidents, crime scenes, and more.

The diagram builder can be added to any [custom record template](/cad/tutorials/customization/creating-custom-record-and-report-types). Select `Diagram` from the `Premade Sections` dropdown.

## Using the Diagram Builder {#using-the-diagram-builder}

Custom records with a diagram section will show an interactive canvas inside the record. Select the edit icon to open up the builder.

### Adding, Editing, and Removing Elements {#adding-editing-and-removing-elements}

#### Adding {#adding}

* Drag-and-drop items from the toolbox to the canvas.

#### Editing {#editing}

* When selected, items can be moved, resized, and edited.
* When an item is selected, the gear icon will open up an options menu for more customization.
* Select multiple items at once with `SHIFT` + `CLICK`.

#### Removing {#removing}

* Select the item(s) and click the trash icon ([or the shortcut](/cad/tutorials/records-management/scene-diagram-builder#shortcuts)) to remove

### Shortcuts {#shortcuts}

The diagram builder is packed with powerful shortcuts to help quickly build the scene.

Hover over any of the top action items for a tooltip listing the shortcut.



<img src="https://docs-assets.sonoransoftware.com/sha256/35/351c51d6b461af4b11922454ac20923839284fc7e184b7a2aab9dcaf648212b4.png" alt="" />

*Diagram Builder: Action Buttons*





<Accordion title="List of Shortcuts">



| Shortcut                               | Description                                                                                     |
| -------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `O`                                    | Opens the item options/settings when an element is selected.                                    |
| `UP ARROW` or `SHIFT` + `UP ARROW`     | Moves the selected item up a layer.<br />Shift option brings it to the very top.           |
| `DOWN ARROW` or `SHIFT` + `DOWN ARROW` | Moves the selected item down a layer.<br />Shift option brings it to the very bottom.      |
| `L`                                    | Locks the selected item(s) from moving.                                                         |
| `G`                                    | Groups or ungroups the selected items together. Use `SHIFT` + `CLICK` to select multiple items. |
| `CTRL` + `Z`                           | Undo last action(s)                                                                             |
| `CTRL` + `SHIFT` + `Z`                 | Redo last action(s)                                                                             |
| `DELETE`                               | Delete selected item(s)                                                                         |
| `CTRL` + `C`                           | Copy selected item(s)                                                                           |
| `CTRL` + `V`                           | Paste copied item(s)                                                                            |



</Accordion>



### Default Images and More {#default-images-and-more}

Communities can also customize the diagram builder to have default images (like a [medical diagram](/cad/tutorials/records-management/scene-diagram-builder#using-the-diagram-builder)) for each record type. Simply hit the edit (pencil icon) in the custom record builder on the diagram to customize and save the template.
