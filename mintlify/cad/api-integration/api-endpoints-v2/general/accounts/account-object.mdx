---
title: Account Object
description: The Account Object represents a single community member's Sonoran CAD
  account.
---

The Account Object is returned by the following endpoints:

* [Get Account](/cad/api-integration/api-endpoints-v2/general/accounts/get-account) — returns a single Account Object
* [Get Accounts](/cad/api-integration/api-endpoints-v2/general/accounts/get-accounts) — returns an array of Account Objects under the `accounts` field

## Schema {#schema}

| Field             | Type              |
| ----------------- | ----------------- |
| `uuid`            | string (uuid)     |
| `username`        | string            |
| `communityUserId` | string            |
| `status`          | integer           |
| `joined`          | string (ISO 8601) |
| `lastLogin`       | string (ISO 8601) |
| `permissions`     | object            |

## Example {#example}

```json
{
  "uuid": "00000000-0000-0000-0000-000000000000",
  "username": "ExampleUser",
  "communityUserId": "player-1234",
  "status": 1,
  "joined": "2026-01-14T18:22:00Z",
  "lastLogin": "2026-04-08T20:55:00Z",
  "permissions": {
    "police": true,
    "admin": false,
    // Rest of the permissions, see below
  }
}
```

## Enumeration Values {#enumeration-values}

### ACCOUNT\_STATUS {#account_status}

| Value | Description |
| ----- | ----------- |
| `0`   | `PENDING`   |
| `1`   | `VALIDATED` |
| `2`   | `EXPIRED`   |
| `3`   | `REMOVED`   |
| `4`   | `BANNED`    |
