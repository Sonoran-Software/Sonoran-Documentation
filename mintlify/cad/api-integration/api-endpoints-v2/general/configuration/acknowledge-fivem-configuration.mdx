The current configuration flow uses [Migrate FiveM Configuration](/cad/api-integration/api-endpoints-v2/general/configuration/migrate-fivem-configuration) and [Get FiveM Configuration](/cad/api-integration/api-endpoints-v2/general/configuration/get-fivem-configuration).

## Authentication and parameters {#authentication-and-parameters}

The earlier draft used an acknowledgement route with a revision parameter. The current resource flow has no acknowledgement step.

## Example request {#example-request}

Use the [startup fetch request](/cad/api-integration/api-endpoints-v2/general/configuration/get-fivem-configuration#example-request) for the current configuration flow.

## Response {#response}
