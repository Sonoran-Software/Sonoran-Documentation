---
title: Register External Bodycam Recording
description: Add a third-party video URL to an account's bodycam clips without uploading the file.
---

`POST` `https://api.sonorancad.com/v2/general/bodycam-recordings/external`

> **Rate limit:** `30 requests per minute` per API key, shared with bodycam uploads.

Register a hosted video URL under a community member's bodycam recordings. The clip can then be [selected in a custom record](/cad/integration-plugins/in-game-integration/available-plugins/bodycam#attach-clips-to-custom-records).

Sonoran CAD saves the URL, without downloading the video. External clip entries do not expire or use your daily recording allowance. The video must remain available at that URL; attaching it to a record does not preserve the file. [Clips uploaded to Sonoran CAD](/cad/api-integration/api-endpoints-v2/general/configuration/upload-bodycam-recording) still expire after 24 hours.

## Request {#request}

Send `application/json` with `Authorization: Bearer YOUR_API_KEY`. The API key determines the community.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `fileUrl` | string | Yes | Absolute HTTPS URL to a playable video file, not a webpage. Maximum 8,192 characters; embedded credentials are not allowed. |
| `accountUuid` | string (UUID) | One target | Recording owner's account UUID. |
| `communityUserId` | string | One target | Recording owner's community user ID. |
| `roblox` | string | One target | Roblox user ID linked to the recording owner's account. |
| `discord` | string | One target | Discord user ID linked to the recording owner's account. |
| `durationMs` | integer | No | Nonnegative duration in milliseconds. Defaults to `0` (unknown). |
| `identId` | integer | No | Nonnegative identifier ID owned by the target account. Defaults to its selected identifier, when available. |
| `unitNumber` | string | No | Unit number; defaults to the resolved identifier's unit number. Maximum 255 characters. |
| `unitLocation` | string | No | Recording location. Maximum 2,000 characters. |
| `originalFileName` | string | No | Filename saved with the clip; defaults to the URL's filename. Maximum 255 characters. |
| `mimeType` | string | No | Video MIME type, such as `video/mp4`. Inferred from recognized URL extensions when omitted. Maximum 100 characters. |

Provide **exactly one** of `accountUuid`, `communityUserId`, `roblox`, or `discord`. The target must already belong to the community. Use a stable URL that viewers can access without additional sign-in.

## Example Request {#example-request}

The SDKs do not yet include a helper for this endpoint. These examples send JSON directly over HTTP.

<Tabs>
<Tab title="Sonoran.lua">

```lua
-- Standalone Lua: luarocks install luasec; luarocks install lua-cjson
local https = require("ssl.https")
local ltn12 = require("ltn12")
local json = require("cjson")

local body = json.encode({
  accountUuid = "USER_ACCOUNT_UUID",
  fileUrl = "https://clips.example.com/chase.mp4",
  durationMs = 90000
})
local response = {}
local _, status = https.request({
  url = "https://api.sonorancad.com/v2/general/bodycam-recordings/external",
  method = "POST",
  headers = {
    ["Authorization"] = "Bearer YOUR_API_KEY",
    ["Content-Type"] = "application/json",
    ["Content-Length"] = tostring(#body)
  },
  source = ltn12.source.string(body),
  sink = ltn12.sink.table(response)
})
print(status, table.concat(response))
```

```json

  "id": "00000000-0000-4000-8000-000000000002",
  "communityUuid": "00000000-0000-4000-8000-000000000003",
  "accountUuid": "00000000-0000-4000-8000-000000000001",
  "username": "OfficerExample",
  "identId": 123,
  "unitNumber": "1A-12",
  "unitLocation": "",
  "originalFileName": "chase.mp4",
  "mimeType": "video/mp4",
  "fileSizeBytes": 0,
  "durationMs": 90000,
  "fileUrl": "https://clips.example.com/chase.mp4",
  "s3Key": "",
  "createdAt": "2026-10-30T12:00:00Z",
  "expiresAt": null,
```

## Errors {#errors}

| Status | Cause |
| --- | --- |
| `400` | Invalid HTTPS URL, missing or multiple target identifiers, invalid metadata, or an identifier belonging to another account. |
| `401` | Missing or invalid API key. |
| `404` | Target account not found or not a member of this community. |
| `429` | Rate limit exceeded. |
