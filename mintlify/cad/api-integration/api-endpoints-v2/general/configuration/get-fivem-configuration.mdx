---
title: Get FiveM Configuration
description: Fetch the configuration for a FiveM server at resource startup.
---

`GET` `https://api.sonorancad.com/v2/fivem/servers/{serverId}/configuration`

Fetch the full configuration for one server when the FiveM resource starts. Each server in a CAD community has its own settings. In CAD, open **Admin > Integrations > In-Game Integration > Manage Your Game Setup**, select the server, and save your changes. The resource reads the saved settings on its next start.

This reference applies to versions of CAD and the FiveM resource that support CAD-managed configuration.

## Authentication and parameters {#authentication-and-parameters}

Send `Authorization: Bearer YOUR_API_KEY`. Replace `serverId` with the positive numeric ID of a server registered in the API key's CAD community. The request has no body.

## Example request {#example-request}

```bash
curl "https://api.sonorancad.com/v2/fivem/servers/1/configuration" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Response {#response}

A `200 OK` response contains a single JSON object with `core` and each plugin as top-level sections. This abbreviated example shows the shape:

```json
{
  "core": {
    "notificationSystem": "auto"
  },
  "bodycam": {
    "enabled": true
  }
}
```

The full response includes default values for missing settings. New communities can fetch the stock configuration immediately. The resource keeps `communityID`, `apiKey`, `serverId`, and `mode` in its local bootstrap settings.

| Status | Meaning |
| --- | --- |
| `200` | Configuration is ready. |
| `401` | The API key is missing or invalid. |
| `404` | The server is unknown to the authenticated community or is waiting for its [migration upload](/cad/api-integration/api-endpoints-v2/general/configuration/migrate-fivem-configuration). The error title identifies which case occurred. |
