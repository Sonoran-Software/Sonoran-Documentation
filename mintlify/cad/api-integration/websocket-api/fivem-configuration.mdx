---
title: FiveM Configuration
description: How the FiveM resource loads CAD-managed settings.
---

Save settings in **Admin > Integrations > In-Game Integration > Manage Your Game Setup** and restart the FiveM resource to load them.

## Delivery {#delivery}

The resource requests the selected server's settings at startup through [Get FiveM Configuration](/cad/api-integration/api-endpoints-v2/general/configuration/get-fivem-configuration).

## Payload {#payload}

The API returns the [full configuration object](/cad/api-integration/api-endpoints-v2/general/configuration/get-fivem-configuration#response). It contains the core settings and each plugin's settings.

## Resource behavior {#resource-behavior}

For a server pending migration, use [Migrate FiveM Configuration](/cad/api-integration/api-endpoints-v2/general/configuration/migrate-fivem-configuration) to upload the existing settings before fetching them.
