---
title: Send Photo
description: This endpoint allows you to send an image popup to a user's CAD from
  in-game for mugshots, evidence photos, etc.
---

<Warning>

This API endpoint requires the **pro** version of Sonoran CAD or higher. For more information, see our [pricing ](/cad/pricing/faq)page.
</Warning>

## Send Photo {#send-photo}

`POST` `https://api.sonorancad.com/general/send_photo`

#### Request Body {#request-body}

| Name | Type   | Description              |
| ---- | ------ | ------------------------ |
| id   | string | Your community's ID      |
| key  | string | Your community's API Key |
| type | string | SEND\_PHOTO              |
| data | array  | Array of request objects |

<Tabs>
<Tab title="200 A successful call will be met with the following response:">

```
Photo sent!
```

</Tab>

<Tab title="400 The following 400 errors may be sent in response:">

```http
INVALID REQUEST TYPE
INVALID COMMUNITY ID
API IS NOT ENABLED FOR THIS COMMUNITY
INVALID API KEY
```

</Tab>

</Tabs>

```javascript
{
    "id": "YOUR_COMMUNITY_ID",
    "key": "YOUR_API_KEY",
    "type": "SEND_PHOTO",
    "data": [
        {
          "apiId": "STEAM:1234", // User API ID
          "url": "https://example.com/photo.png" // Photo URL
    ]

```
