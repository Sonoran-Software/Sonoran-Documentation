## Get Account Identifiers {#get-account-identifiers}

`POST` `https://api.sonorancad.com/emergency/get_identifiers`

This endpoint allows you to retrieve all unit identifiers for a specified account in your community.

#### Request Body {#request-body}

| Name                                   | Type   | Description              |
| -------------------------------------- | ------ | ------------------------ |
| id\*   | string | Your community's ID      |
| key\*  | string | Your community's API Key |
| type\* | string | GET\_IDENTIFIERS         |
| data\* | array  | Array of request objects |

<Tabs>

```javascript
{
    "selectedIdent": 1,
    "identifiers": [
        {
            "id": 12,
            "accId": "00000000-0000-0000-0000-000000000000",
            "status": 0,
            "isPanic": false,
            "location": "",
            "aop": "Los Santos",
            "data": {
                "unitNum": "A-10",
                "name": "John Doe",
                "district": "Los Santos",
                "department": "LSPD",
                "subdivision": "Patrol",
                "rank": "Officer",
                "group": "CAR-51",
                "communityUserId": "license:abc123"

```

</Tab>

```http
INVALID REQUEST TYPE

```
