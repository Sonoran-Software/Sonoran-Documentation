## How are API calls sent? {#how-are-api-calls-sent}

The v2 API uses standard HTTP methods and JSON request bodies where applicable. See [Authentication](/cad/api-integration/api-endpoints-v2/authentication) for the base URL and required headers.

## Can I integrate this with my gamemode/framework? {#can-i-integrate-this-with-my-gamemode-framework}

Yes, our API calls can be integrated into nearly any gamemode with nearly any programming language.

We provide a library of drag-and-drop plugins written in Lua.<br />

Yes. Requests are limited per API key. Check the individual endpoint page for its limit.
