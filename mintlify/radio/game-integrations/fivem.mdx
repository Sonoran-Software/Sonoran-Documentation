If you’re using a release that predates **FiveM Settings**, see the [previous guide](https://github.com/Sonoran-Software/Sonoran-Documentation/blob/8c017dc2fe962a3b750d4b34bb53aa0fb72bcb54/mintlify/radio/game-integrations/fivem.mdx).

1. [Install the FiveM resource](/radio/game-integrations/fivem/installing-the-in-game-resource).
2. [Learn the in-game radio controls](/radio/game-integrations/fivem/in-game-radio/using-the-in-game-radio).
3. Configure the server in [FiveM Settings](/radio/game-integrations/fivem/installing-the-in-game-resource#configuration-values) and add in-game equipment in [FiveM Placements](/radio/game-integrations/fivem/installing-the-in-game-resource#placements).

For installation or audio problems, see [FiveM Troubleshooting](/radio/game-integrations/fivem/troubleshooting). Shared channels and dispatch settings are covered in [Using Sonoran Radio](/radio/tutorials/usage).

Use [Dispatch AI](/radio/game-integrations/fivem/fivem) for voice channel controls, timers, CAD actions, emergency call readouts, and GPS routing.
