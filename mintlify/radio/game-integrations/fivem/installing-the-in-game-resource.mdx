For an older install, use the [previous installation guide](https://github.com/Sonoran-Software/Sonoran-Documentation/blob/8c017dc2fe962a3b750d4b34bb53aa0fb72bcb54/mintlify/radio/game-integrations/fivem/installing-the-in-game-resource.mdx).

Open your community in Sonoran Radio and go to **Admin > Game Integration**. Select **FiveM** as the community's game, then open **FiveM Installation**.

## One-click Installation with RocketNode {#one-click-installation-with-rocketnode}

1. In **FiveM Installation**, select **RocketNode** and copy the **Community ID** and **API Key**.
2. In the RocketNode Game Panel, open **Configuration > Sonoran Installer > Radio**.
3. Paste the community ID and API key, then select **Install Sonoran**.

[View RocketNode FiveM hosting](https://sonoran.link/p62G7ncv). Use code `SONORAN` at checkout.

## Install the FiveM Resource {#install-the-fivem-resource}

### 1. Download the ZIP {#id-1.-download-the-zip}

Select **Manual Install**. Under **Radio Server**, select the server you want to connect, or choose **New Server**. Select **Download ZIP**.

The ZIP includes a `config.lua` with your community ID, API key, and Radio server ID. Keep the API key private.

### 2. Extract the ZIP File {#id-2.-extract-the-zip-file}

Extract the `[sonoranradio]` folder into your FiveM server's `resources` directory. Keep `sonoranradio` and `sonoranradio_updatehelper` together inside that folder.

<img src="https://docs-assets.sonoransoftware.com/sha256/34/34d81179f8580b118937c44ff267532f8a2d321e4b7719082639eafef79cf9a5.png" alt="FiveM resources folder with sonoranradio and sonoranradio_updatehelper inside [sonoranradio]" />

### 3. Update Your Server Config {#id-3.-update-your-server-config}

Add the following line to `server.cfg` after the lines that start your framework and inventory resources, then start or restart your FiveM server.

```text
exec @sonoranradio/sonoranradio.cfg
```

<Warning>
Use the `exec` line to start Sonoran Radio. Starting `sonoranradio_updatehelper` manually or using `ensure [sonoranradio]` can cause server crashes.
</Warning>

In **FiveM Installation**, check **Resource connection** for the selected **Radio Server**. A **Last fetched** timestamp confirms the resource has read that server's settings.

## FiveM Settings {#configuration-values}

Open **Admin > Game Integration > FiveM Settings** and select your **Radio Server**. Each server has its own settings.

| Section | What to configure |
| --- | --- |
| **Radio** | **Default skin ID**, **Escape key behavior**, **Radio chatter and scanners**, **Match in-game speech to radio transmissions**, **Include background audio**, transmit animation, death and revival, and panic transmission. |
| **Permissions and frames** | **Use guest login**, **Sync player names to Radio**, **Sync permissions from ACE**, ACE access requirements, and **Frame permission mode**. |
| **Inventory** | **Require an inventory item**, radio item, and scanner item. |
| **Calls and integrations** | Emergency call commands, **Phone integration**, **Luxart resource name**, pursuit callouts, and CAD on-scene status. |
| **Signal and equipment** | Vehicle repeaters, physical equipment visibility, repair times and permissions, water degradation, and geo-channel switching. |
| **Jammers** | Jammer setup, definitions, and access. |
| **Notifications** | **Notification provider**, notification title, and ox_lib notice settings. |
| **Default keybinds** | The default keys for in-game radio controls, channel and group navigation, calls, and automation. |
| **Zones** | Emergency call, geo-channel, and signal degradation zones. |

Settings save automatically. When the restart banner appears, copy the restart command and run it in the FiveM server console to apply the changes.

```text
exec @sonoranradio/sonoranradio.cfg
```

### FiveM Placements {#placements}

Open **Admin > Game Integration > FiveM Placements** and select your **Radio Server**. Under **Placement type**, choose **Towers and equipment**, **Tone speakers**, **Jammer placements**, **Scanners**, **Earpieces**, or **Mobile repeaters**. Run the restart command from the banner after adding, editing, or removing a placement.

If the panel is waiting for placements, start the updated resource on that server. On startup, the resource imports existing placement files for any types that have yet to sync.

### Migrate existing settings {#migrate-existing-settings}

1. Update and start the Sonoran Radio resource on your FiveM server. Keep the existing `config.lua` and placement files during the update.
2. In **FiveM Installation**, select the same **Radio Server**. Copy the command from **Migrate local settings** and run it in the FiveM server console.

   ```text
   sonoranradio migrate
   ```

3. Wait for the console to confirm the migration. Run `exec @sonoranradio/sonoranradio.cfg` in the FiveM server console to apply the settings and import placements on startup.
4. Confirm the resource has fetched settings, then review **FiveM Settings** and **FiveM Placements** for that server.

The migration preserves your original files and keeps any settings already saved in Radio Admin. Start the migration before editing settings in the panel if you want to import your local settings.

## Updates {#updates}

The resource checks for updates when it starts and roughly once per hour when automatic updates are enabled. By default, it waits until the server is empty before restarting to apply an update.
