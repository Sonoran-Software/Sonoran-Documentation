Use [Dispatch AI](/radio/tutorials/usage/dispatch-ai) to change radio channels, manage scanned channels, set timers, and work with CAD. FiveM also supports emergency call readouts and in-game GPS routing.

## Setup {#setup}

1. Complete the [common Dispatch AI setup](/radio/tutorials/usage/dispatch-ai#common-setup).
2. Install the [FiveM Radio resource](/radio/game-integrations/fivem/installing-the-in-game-resource).
3. Sign in to the in-game radio with your Sonoran account. For CAD actions, use that account in CAD or complete the in-game `/link` flow.
4. Use the wake word while transmitting, or set **Toggle Dispatch AI** under **Admin > Game Integration > FiveM Settings > Default keybinds > Calls and automation**. Select the appropriate **Radio Server** and use the restart command after the setting saves. Players can change their own Dispatch AI keybind in-game.

## Emergency Call Readouts {#emergency-call-readouts}

1. Connect the intended CAD server under **Admin > Dispatch AI**.
2. Open **Admin > Game Integration > FiveM Settings** and select the **Radio Server** running Dispatch AI.
3. Expand **Zones** and select **Emergency Zones**.
4. Draw a zone and select it to assign the channels that should receive calls in that area.
5. Generate a 911 call in the linked CAD server with coordinates inside a zone.

Dispatch AI creates a dispatch call, removes the original 911 call, and reads it over the zone's assigned channels. Calls without coordinates or outside the zones are not read automatically.



## GPS Routing {#gps-routing}

| Destination | Example |
| --- | --- |
| Postal code | “Dispatch, route me to postal 123.” |
| Dispatch call | “Dispatch, route me to the robbery call.” |
| Another unit | “Dispatch, route me to unit B-11.” |

Postal routing requires **Nearest Postal** or another resource supporting `/postal <id>`. Routing to a unit uses that unit's available CAD coordinates.



<Accordion title="Automatic en-route and on-scene status">



With **Nearest Postal v1.5.4 or newer**, AI GPS routing can set your CAD status to en-route and then on-scene when you arrive.

In [FiveM Settings](/radio/game-integrations/fivem/installing-the-in-game-resource#configuration-values), select your **Radio Server** and open **Calls and integrations > CAD on-scene status**. Enable **Set CAD status when arriving on scene**. Use **On-scene distance (meters)** to set how close the unit must get to the waypoint, **CAD on-scene status ID** to set the status, and **On-scene timeout (milliseconds)** to set how long the resource waits for arrival. Run the restart command after the settings save.



</Accordion>



For channel changes, timers, and current-call readbacks, see the [shared commands](/radio/tutorials/usage/dispatch-ai#radio-commands).
