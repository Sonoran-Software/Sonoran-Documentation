## Using the Radio Jammer {#using-the-radio-jammer}

### Enabling the Jammer {#enabling-the-jammer}

1. In **Admin → Game Integration → FiveM Settings**, select your **Radio Server**.
2. Open **Jammers → Setup** and enable **Radio jammers**. Use **Jammer definitions** to configure handheld and static jammer types.
3. In **Jammers → Access**, choose who can use jammers with **Jammer permission mode**.
4. [Restart the resource after the settings save.](/radio/game-integrations/fivem/installing-the-in-game-resource#configuration-values)

### Opening in Standalone {#opening-in-standalone}

Use `/radio jammers` to open the jammer menu. If you've changed **Jammer menu subcommand** under **Jammers → Setup**, use that value after `/radio`.

### Opening in a Framework Server (QBCore, Qbox, etc.) {#opening-in-a-framework-server-qbcore-qbox-etc}

With a radio jammer item in their inventory, players can use it to open the jammer menu.

[View our complete list of supported FiveM frameworks an inventories.](/radio/game-integrations/fivem/fivem-inventories)

## Permanent Jammers {#permanent-jammers}

Permanent Jammers are available to everybody at configurable locations across the map.

#### Configuring Permanent Jammers {#configuring-permanent-jammers}

Use `/radio jammers` in-game to add, move, or delete permanent jammers.

To edit placements from the portal, open **Admin → Game Integration → FiveM Placements**. Select your **Radio Server** and choose **Jammer placements** under **Placement type**. Select **Add** or open an existing entry to edit its position, model, range, or strength. Select **Apply**, then [restart the resource](/radio/game-integrations/fivem/installing-the-in-game-resource#placements). New servers start with an empty jammer placement list.

## Jamming Radio Effect {#jamming-radio-effect}

In-game radio screens will reflect a jamming effect, with the intensity based on the jammer strength.

## Developers {#developers}

### Ace Permissions {#ace-permissions}

Under **FiveM Settings → Jammers → Access**, choose **ACE** for **Jammer permission mode** to require the configured **Jammer ACE permission**. The default grant is `sonoranradio.jammers`. Add it in `server.cfg`.

You can also set **ACE permission (optional)** on a type under **Jammer definitions**. The default handheld jammer uses `sonoranradio.jammer_handheld`. For job-based access, use **Jammer jobs and grades** with the **QBCore** or **ESX** permission mode. Select **QBCore** for Qbox servers.

[Learn how to grant ACE permissions.](/radio/game-integrations/fivem/in-game-radio/configuring-ace-permissions)

### Giving the Jammer Item (QBCore) {#giving-the-scanner-item-qbcore}

Use your server's item-granting method to give the jammer item. For example, run this command in chat.

```
/giveitem <playerId> sonoran_radio_jammer_handheld 1
```
