## Audio Examples {#audio-examples}

### Nearby Radio {#nearby-radio}

If someone nearby has a radio, you'll hear the radio traffic they’re listening to coming from their device. The closer they are the louder the radio traffic will be. However, if they're [using an earpiece](/radio/game-integrations/fivem/in-game-radio/hear-nearby-radio-chatter#in-game-earpiece), the audio won’t be audible to others.

### Radio in Vehicle {#radio-in-vehicle}

When someone with a [nearby radio](/radio/game-integrations/fivem/in-game-radio/hear-nearby-radio-chatter#nearby-radio) enters a vehicle, the radio audio will become muffled. However, if a door is open, or a window is down or broken, the audio will become clearer and louder again.

### Nearby Emergency Phone Call {#nearby-emergency-phone-call}

When someone is [making an emergency call to a dispatcher](/radio/tutorials/usage/dispatch-panel/emergency-calls), nearby users will faintly hear the dispatcher's voice coming from the caller's phone.

### Nearby Radio Scanner {#nearby-radio-scanner}

When someone is carrying (or has placed down) [a radio scanner](/radio/game-integrations/fivem/in-game-radio/radio-scanners), nearby users will hear the channel that the scanner is set to.

## Usage {#usage}

### Default Chatter Volume {#default-chatter-volume}

The volume of nearby radio chatter matches the volume setting of the emitting radio. Users with an active radio can [adjust its volume using a hotkey or the settings menu](/radio/game-integrations/fivem/in-game-radio/using-the-in-game-radio#adjust-volume).

### Adjust Volume {#adjust-volume}

Players can adjust the nearby radio volume in-game using the `/radiovolume` command.

Ex: `/radiovolume 75` sets the nearby radio to 75% volume.



<Accordion title="Technical Information">



When a player is within 15 game units of an active radio, they will hear the live chatter from the nearest radio. If multiple radios within range are tuned to different channels, the player will hear all those channels blended, but the sound will primarily emit from the closest radio source.

_This feature is experimental and subject to both change and improvements._



</Accordion>



## In-Game Earpiece {#in-game-earpiece}

Some communities may offer custom EUP (clothing and accessories) that players can use to personalize their characters. For radio users, an option to wear an earpiece (headphones) could be useful, allowing them to listen to radio chatter privately without others nearby overhearing.

Whenever a user inserts or removes a configured in-game earpiece, a notification will be displayed confirming that others around you can or can not hear your radio.

Communities can easily select which clothing items will be treated as a radio earpiece.

### Manual Earpiece IDs (Advanced) {#manual-earpiece-ids-advanced}



<Accordion title="Manually Configure Earpiece IDs">



The `earpieces.json` file defines earpiece items (custom EUP prop IDs) that block radio chatter from being heard nearby.

Component IDs

Look [here](https://docs.fivem.net/natives/?_0x829F2E2) for the component IDs for props (hats, glasses, earpieces, etc.). To find component IDs for drawables (shirts, pants, backpacks, etc.), look [here ](https://docs.fivem.net/natives/?_0x262B14F48D29DE80)and add 14 to the number.

For example, to exclude a clothing item under ACCESSORIES, it might look like this:

```lua
{
  componentId = 22, -- accessories (8) + offset (14) is 22
  drawableId = 78,  -- Number in vMenu
  texture = 0,      -- Number in vMenu (or 0 for all textures)
}
```



</Accordion>
