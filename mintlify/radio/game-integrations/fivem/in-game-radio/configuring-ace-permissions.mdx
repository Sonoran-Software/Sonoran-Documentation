## **Command ACE Permissions** {#command-ace-permissions}

ACE permissions allow you to restrict what users have access to certain commands.

ACE permissions are configured in your `server.cfg` file.\
To keep them organized, you can place them in `permissions.cfg` in the same directory and add `exec permissions.cfg` to `server.cfg`.

### **1. Create a Permission Group** {#id-1.-create-a-permission-group}

Here, we'll create an `admin` ACE group that has access to all of the `sonoranradio.example` categorized permissions.

```
# ACE group name 'admin' for 'sonoranradio.example' permission category
add_principal group.admin sonoranradio.example
```

### **2. Assign Permissions to the Group** {#id-2.-assign-permissions-to-the-group}

This adds all of the Sonoran Radio permissions (configuring repeaters, using the radio, and repairing repeaters) to the `sonoranradio.example` category that the `admin` ACE group has access to.



<Accordion title="Group Permission Example">



```
# Add permissions to the ace category "sonoranradio.example"

# Tower Configuration Menu
add_ace sonoranradio.example command.radiomenu allow

# Radio access when Require ACE for radio access is enabled
add_ace sonoranradio.example sonoranradio.use allow

# Guest access when Require ACE for guest access is enabled
add_ace sonoranradio.example sonoranradio.guest allow

# Radio Display Name Command Access
add_ace sonoranradio.example sonoranradio.displayname allow

# Auto-approve community members when Sync permissions from ACE is enabled
add_ace sonoranradio.example sonoranradio.autoapprove allow

# Tower repair when Require ACE for tower repair is enabled
add_ace sonoranradio.example sonoranradio.repair allow

# Connected users list when Require ACE for the radio users list is enabled
add_ace sonoranradio.example sonoranradio.radiousers allow

# Scanner access when Require ACE for scanners is enabled
add_ace sonoranradio.example sonoranradio.scanner allow

# Access to private channel 123
add_ace sonoranradio.example sonoranradio.channel.123 allow

# Jammer access when Jammer permission mode is ACE and this is the configured permission
add_ace group.admin sonoranradio.jammers allow

# Access to the handheld jammer when this is configured on its definition
add_ace group.admin sonoranradio.jammer_handheld allow
```



</Accordion>



### **3. Add Users to the ACE Group** {#id-3.-add-users-to-the-ace-group}

This grants a user the `admin` ACE permission group, specific to their in-game license ID.

```
add_principal identifier.license:{GTA License} group.admin
```

## ACE Permission Sync {#ace-permission-sync}

<Warning>

**ACE permission sync will override all existing user permissions.**

**Any manually granted permissions will be removed**, ensuring the user has only the permissions configured through ACE.
</Warning>

ACE permission sync allows you to automatically approve users in the radio community, grant access to private channels, and give user permissions like name changes, kick, etc.

This sync is ran whenever you turn the radio on and connect.

[View other ways to manage user permissions.](/radio/tutorials/getting-started/invite-and-manage-users)

### Enable ACE Permission Sync {#enable-ace-permission-sync}

In **Admin → Game Integration → FiveM Settings**, select your **Radio Server**. Open **Permissions and frames → Accounts** and enable **Sync permissions from ACE**. [Restart the resource after the setting saves.](/radio/game-integrations/fivem/installing-the-in-game-resource#configuration-values)

The radio access switches are under **Permissions and frames → ACE access**. Find **Require ACE for tower repair** under **Signal and equipment → Repairs**.

### Guest Login {#guest-login}

Players can [sign in as a guest](/radio/game-integrations/fivem/in-game-radio/using-the-in-game-radio#login-as-guest) from the in-game radio. ACE permission sync also applies configured ACE grants to guests.

<Info>

**Forced Guest Login**

Enable **Use guest login** under **FiveM Settings → Permissions and frames → Accounts** to sign eligible players in as guests automatically. Their radio permissions come from ACE.
</Info>

#### Restrict Guest Logins {#restrict-guest-logins}

Under **FiveM Settings → Permissions and frames → ACE access**, enable **Require ACE for guest access** to require `sonoranradio.guest` for guest sign-in. This setting is disabled by default. If **Require ACE for radio access** is also enabled, grant `sonoranradio.use` as well.

### Permission Sync Options {#permission-sync-options}



<Accordion title="Community Approval">



With **Sync permissions from ACE** enabled, grant `sonoranradio.autoapprove` to automatically approve members when they connect in-game.



</Accordion>





<Accordion title="Private Channels">



Access to private channels can be granted via ACE permissions.

You will need the channel ID ([visible in the dispatch panel](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#channel-ids) or [in-game radio](/radio/game-integrations/fivem/in-game-radio/using-the-in-game-radio/fivem-keybinds-and-commands#copying-channel-and-scan-list-ids)) for each channel ACE permission.

`sonoranradio.channel.123`



</Accordion>





<Accordion title="General Permissions">



General radio community permissions can also be granted via ACE permissions.

Admin: `sonoranradio.admin`

Approve Members: `sonoranradio.communityapprove`

Change Display Name: `sonoranradio.setmynickname`

Manage Display Name: `sonoranradio.setnickname`

Kick from Community: `sonoranradio.communitykick`

Kick from Radio: `sonoranradio.radiokick`

Move Radio Users: `sonoranradio.radiomove`

Play Dispatch Tones: `sonoranradio.radiotones`

Override Talkover Protection: `sonoranradio.radiotalkover`

Stun Radio Users: `sonoranradio.radiostun`

</Accordion>



### Permission Sync Example {#permission-sync-example}



<Accordion title="Permission Sync Configuration Example">



```
# Grant the ADMIN radio permission to everyone in the admin group
add_ace group.admin sonoranradio.admin allow

# Grant the talkover-override permission to everyone in the admin group
add_ace group.admin sonoranradio.radiotalkover allow

# Grant the radio-stun permission to everyone in the admin group
add_ace group.admin sonoranradio.radiostun allow

# Auto-approve everyone in the leo group
add_ace group.leo sonoranradio.autoapprove allow
```



</Accordion>
