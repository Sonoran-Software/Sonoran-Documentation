FiveM radio frames are managed in the Radio panel under **Admin** > **Overlay**. The same editor supplies the desktop overlay.

Add a **Panic** control to layouts that need one. See [Sonoran CAD Integration](/radio/tutorials/integrations/sonoran-cad-integration) for the FiveM CAD plugin and desktop overlay panic setup. Desktop overlay synchronization requires the CAD API link under **Admin** > **Dispatch AI**.

## Create or edit a frame {#create-or-edit-a-frame}

Select **FiveM** in **Admin** > **Game Integration**, then follow [Create a custom overlay](/radio/tutorials/usage/desktop-overlay#create-a-custom-overlay). Upload your artwork, position the screen and buttons, and select **Save changes**. Uploading new custom artwork requires **Pro**.

With Pro, [Overlay AI](/radio/tutorials/usage/desktop-overlay/overlay-ai) can generate your radio frame artwork and editable screen from text or reference photos. Start with a blank frame or refine an existing one, then select **Save changes**.

Use an updated FiveM resource. With your server's push URL configured, saving sends the updated frames to connected players. The resource also checks on startup and roughly every 30 seconds. If a check fails, it keeps the last successfully loaded frames and tries again.

## Set a layout for vehicle classes {#set-a-layout-for-vehicle-classes}

The **On-foot**, **Vehicle**, and **Aircraft** layout controls appear when the community has **FiveM** selected as its game. A frame can have several vehicle layouts, each with its own image, screen, buttons, and vehicle classes.

1. In **Admin** > **Overlay**, select the frame you want to edit and choose **Vehicle** or **Aircraft**.
2. Select **Add layout**, or choose an existing entry from **Vehicle layout** or **Aircraft layout**.
3. Under **Vehicle classes**, select the classes that should use that layout. For example, class `18` is **Emergency**, while `15` and `16` are aircraft. Clearing all selected classes makes a vehicle layout match every class.
4. Use **Change image** and the editor controls to position its screen and buttons. Use the up and down arrows to set layout order, then select **Save changes**.

FiveM uses the **first** vehicle layout whose class list matches the vehicle. Put a layout that matches all classes after more specific layouts. Aircraft-only layouts appear under **Aircraft**; layouts with any non-aircraft class appear under **Vehicle**. The order is shared between those tabs.

The radio automatically applies that layout when you enter a matching vehicle and returns to On-foot when you exit. If no vehicle layout matches, it uses On-foot. See [FiveM Frame Changes](/radio/game-integrations/fivem/in-game-radio/fivem) for examples and troubleshooting.

## Change your frame in game {#change-your-frame-in-game}

1. Open the radio's **Settings**.
2. Select the **FiveM** tab.
3. Choose a frame from **Radio Frame**.

Only frames available to your player appear in the list.

## Restrict frame access {#restrict-frame-access}

1. In Radio Admin, open **Game Integration** > **FiveM Settings** and select your **Radio Server**.
2. Expand **Permissions and frames**. Under **Frame access**, choose a **Frame permission mode**.
3. Configure the rules for the selected mode:

| Mode | Rules |
| --- | --- |
| **None** | Players can select any available frame. |
| **ACE** | Open **ACE frame permissions** and select **Add group**. Name the group, pick its **Allowed frames**, and select **Add ACE permission** to add an ACE. Any listed ACE permission grants access to those frames. |
| **QBCore**, **Qbox**, or **ESX** | Open **Frame department permissions** and select **Add department**. Enter a department ID and name, then pick its **Allowed frames**. Select **Add job**, enter its **Job ID**, and use **Add grade** for each grade that should have access. Grades match exactly. |

Select **Apply** after editing ACE or framework rules. Use **Restart Sonoran Radio** to copy the restart command and run it in the FiveM server console. The frame picker uses frames from **Admin** > **Overlay**. Existing assignments to migrated frames still work.

For example, create a **County Patrol** ACE group, choose the patrol frames in **Allowed frames**, and add `sonoranradio.patrol`. Grant that ACE to the players who need those frames. [Sonoran CMS can manage ACE permissions from community roles.](/cms/integration-capabilities/sonoran-radio-sync)
