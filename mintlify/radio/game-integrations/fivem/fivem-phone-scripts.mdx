## LB Phone {#lb-phone}

Players can use LB Phone to call a Sonoran Radio dispatcher from their in-game phone.

### Configuration {#configuration}

1. Start the `lb-phone` resource before Sonoran Radio in `server.cfg`.
2. In **Admin > Game Integration > FiveM Settings**, select your **Radio Server** and open **Calls and integrations > Game resources**.
3. Set **Phone integration** to **lb-phone**, then run the restart command after the setting saves.
4. [Customize the emergency number and in-game call help.](/radio/tutorials/usage/dispatch-panel/emergency-calls#customize-the-emergency-number-and-banner)

### Usage {#usage}

In LB Phone, dial 911 ([or your customized number](/radio/tutorials/usage/dispatch-panel/emergency-calls#customize-the-emergency-number-and-banner)) to connect with a Sonoran Radio dispatcher. Press the end call button to hang up.
