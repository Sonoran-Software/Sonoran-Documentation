## What is this offer? {#what-is-this-offer}

<Warning>

This script requires the **pro** version of Sonoran Radio **standalone**.

[Click to learn more about Sonoran Radio standalone!](/radio)
</Warning>

Big Daddy's radio animation script enhances your Sonoran Radio experience by adding new in-game animations. As one of the most popular scripts of its kind, it offers versatile options based on where your radio is positioned—whether on your chest, shoulders, or handheld. This provides a more immersive and personalized interaction.

## Download and Installation {#download-and-installation}

### 1. Download the Script and Product Key {#id-1.-download-the-script-and-product-key}

Create an account and [download the latest script resource](https://sonoran.link/bigdaddy) from Big Daddy Scripts.

In the account portal, select your recent order and copy the product key.

### 2. Install The Script {#id-2.-install-the-script}

#### A. Extract {#a.-extract}

Extract the script to your server's `resources` folder.

#### B. License Key {#b.-license-key}

In the `settings.ini` file, paste your license key.



<img src="https://docs-assets.sonoransoftware.com/sha256/27/2727d783ffe3f0d98b611747949a238135f8ba3b0070f21ccd7df44b163098bf.png" alt="" width="375" />

*Big Daddy - Product Key*



#### C. Ensure the Resource {#c.-ensure-the-resource}

In `server.cfg`, start the animation resource after the Sonoran Radio startup command.

```text
exec @sonoranradio/sonoranradio.cfg
ensure BigDaddy-RadioAnimation
```

Sonoran Radio detects a resource named `BigDaddy-RadioAnimation` and disables its default transmit animation. To disable the default animation yourself, go to **Admin > Game Integration > FiveM Settings**, select your **Radio Server**, then enable **Disable transmit animation** under **Radio > Transmit animation**. Run the restart command after the setting saves.

### 3. Enjoy! {#id-3.-enjoy}

Once in-game, you can use the `/radioanim` command to open up the customization menu.

This script will automatically detect when you are talking on your Sonoran Radio.

<Info>

This script also makes **users talk on their in-game microphone when they talk on the radio**.

To disable this, turn off **Match in-game speech to radio transmissions** under **FiveM Settings > Radio > Radio and audio** for your **Radio Server**. Set `TalkSync` to `false` in Big Daddy's animation resource's `settings.ini`, then restart both resources.
</Info>

[See the documentation for more information about configuration options and commands.](https://wiki.bigdaddyscripts.com/documentation/sonoran-radio-animation/)
