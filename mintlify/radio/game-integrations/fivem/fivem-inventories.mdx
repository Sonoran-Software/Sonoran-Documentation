If you’re using a release that predates **FiveM Settings**, see the [previous guide](https://github.com/Sonoran-Software/Sonoran-Documentation/blob/8c017dc2fe962a3b750d4b34bb53aa0fb72bcb54/mintlify/radio/game-integrations/fivem/fivem-inventories.mdx).

Open **Admin > Game Integration > FiveM Settings**, select your **Radio Server**, and expand **Inventory**. Start your framework and inventory resources before Sonoran Radio.

## QBCore {#qbcore}

QBCore inventory support for the radio and [radio scanner](/radio/game-integrations/fivem/in-game-radio/radio-scanners) items is automatically detected.

### Configuration {#configuration}

#### Inventory Restriction {#inventory-restriction}

Enable **Require an inventory item** to restrict radio and scanner access to players who carry the corresponding item.

#### Inventory Item {#inventory-item}

Under **Radio item** and **Scanner item**, set each item's ID, label, weight, and description. The default IDs are `sonoran_radio` and `sonoran_radio_scanner`.

Run the restart command after your settings save. If the inventory still shows the old item details, restart the FiveM server to reload the item definitions.

### Supported Inventories (QBCore) {#supported-inventories-qbcore}

Currently, the following QBCore inventories are supported:

* QBCore Inventory
* OX Inventory
* QS Inventory
* Core Inventory

## Qbox {#qbox}

### Configuration {#configuration-1}

#### Inventory Restriction {#inventory-restriction-1}

Enable **Require an inventory item** to restrict radio and scanner access to players who carry the corresponding item.

#### Inventory Item {#inventory-item-1}

Add the entries below to your `ox_inventory/data/items.lua` file. If you use custom IDs, match the entry keys to **Radio item ID** and **Scanner item ID** in **FiveM Settings > Inventory**. Edit the labels, weights, and descriptions in the Ox Inventory file.

Restart the FiveM server to load the item definitions and saved Radio settings.



<Accordion title="Ox Inventory Items File">



```lua
['sonoran_radio_scanner'] = {
        label = 'Sonoran Radio Scanner',
        description = 'Listen to radio chatter with the Sonoran Radio Scanner',
        weight = 1,
        client = {
            image = 'radio.png',
            remove = function(total)
                if total < 1 then
                    TriggerServerEvent('SonoranRadio::DropItem::Scanner')
                end
            end
        }
    },
    ['sonoran_radio'] = {
        label = 'Sonoran Radio',
        description = 'Communicate with others through the Sonoran Radio',
        weight = 1,
        client = {
            image = 'radio.png'
        }
    },
```



</Accordion>
