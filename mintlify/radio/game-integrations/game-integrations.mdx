Choose your game for installation and game-specific features.

| Game | Setup | Radio controls |
| --- | --- | --- |
| [FiveM](/radio/game-integrations/fivem) | Install the FiveM resource. | In-game radio |
| [Roblox / ER:LC](/radio/game-integrations/roblox) | Link your ER:LC private server and Roblox account. | Desktop app and overlay |
| [Arma 3](/radio/game-integrations/arma-3) | Install the Arma mod on the server and player computers. | Desktop app and overlay |

**[Star Citizen](/radio/game-integrations/star-citizen):** Coming soon.


Community setup, channels, and dispatch controls are covered in [Getting Started](/radio/tutorials/getting-started) and [Using Sonoran Radio](/radio/tutorials/usage).
