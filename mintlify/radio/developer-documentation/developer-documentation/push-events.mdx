## Push Event Address {#push-event-address}

Push events are sent to your community's `pushUrl` (full IP/port) set in the [set-server-ip](/radio/developer-documentation/developer-documentation/api-endpoints/community-server/set-server-ip) API endpoint. This endpoint should be called on startup.

Push events can be authenticated by comparing the event's `id` and `key` to your community ID and API key.
