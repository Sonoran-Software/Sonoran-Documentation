title: Get Community Channels
description: Get configured channel groups and channels for a specific Sonoran Radio
  server.

## Get Community Channels {#get-community-channels}

`GET` `/v2/servers/:communityId/channels`

> **Rate limit:** `6 requests per minute`\
> Authenticated v2 endpoints are rate limited per API key rather than per IP address.

Returns channel groups and channel definitions for the selected server.

**Headers**

| Name          | Value                        |
| ------------- | ---------------------------- |
| Authorization | `Bearer <community-api-key>` |

**Examples**

<Tabs>
<Tab title="Sonoran.lua">

```lua
local response = client.radio:getCommunityChannelsV2()
```

</Tab>

<Tab title="Sonoran.js">

```javascript
const response = await instance.radio?.getCommunityChannelsV2();
```

</Tab>

<Tab title="Sonoran.py">

```python
response = instance.radio.getCommunityChannelsV2()
```

</Tab>

<Tab title="Sonoran.Net">

```csharp
var response = await sonoran.Radio.getCommunityChannelsV2();
```

</Tab>

<Tab title="OpenAPI">

```yaml
openapi: 3.1.0
paths:
  /v2/servers/{communityId}/channels:
    get:
      security:
        - bearerAuth: []
```

</Tab>

<Tab title="cURL">


</Tab>

</Tabs>

## Response {#response}

Successful requests return `application/json`.

```json
{
  "groups": [],
  "channels": [
    {
      "id": 101,
      "name": "Law Dispatch"
    }
  ]
}
```
