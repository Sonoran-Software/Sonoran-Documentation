## Move FiveM settings to Radio Admin {#move-fivem-settings-to-radio-admin}

On a managed-settings release, update the resource, then run `sonoranradio migrate` in the FiveM server console before saving settings in the portal. Restart the resource after the console confirms migration. The command keeps your existing files on disk and uses any settings already saved for the selected server.

[Full installation and migration steps](/radio/game-integrations/fivem/installing-the-in-game-resource#migrate-existing-settings)

### Gameplay settings {#configuration-file}

Open **Admin > Game Integration > FiveM Settings** and select your **Radio Server**.

| For settings from earlier releases | Open |
| --- | --- |
| Escape behavior, chatter, background audio, animations, and automatic panic transmission | **Radio** |
| Display name sync, guest access, and frame access | **Permissions and frames** |
| Radio and scanner inventory items | **Inventory** |
| Emergency call commands, phone scripts, pursuit callouts, and CAD on-scene updates | **Calls and integrations** |
| Repair timers, water signal loss, and geo-channel switching | **Signal and equipment** |
| Jammer settings, permissions, and definitions | **Jammers** |
| Notification provider and timing | **Notifications** |
| Default controls for players | **Default keybinds** |
| Emergency, geo-channel, and signal degradation zones | **Zones** |

### ACE permissions {#ace-permissions}

Keep your existing ACE grants in `server.cfg`. Set the access requirements in **Permissions and frames** and the repair requirements in **Signal and equipment > Repairs**. [Configure ACE permissions](/radio/game-integrations/fivem/in-game-radio/configuring-ace-permissions)

### Placement files {#towers-file}

On startup, the updated resource imports existing placements for the selected server. Open **Admin > Game Integration > FiveM Placements** to edit towers, racks, cell repeaters, tone speakers, static jammers, scanners, earpieces, and mobile repeaters. Restart the resource after saving portal changes. [Edit placements](/radio/game-integrations/fivem/installing-the-in-game-resource#placements)

### Community and server credentials {#configuration-file-1}

A new download for the selected server fills in the community ID, API key, and Radio server ID. Keep the matching credentials in your existing installation if you update it in place. [Download the FiveM resource](/radio/game-integrations/fivem/installing-the-in-game-resource#install-the-fivem-resource)

## Migrate local radio frames {#migrate-local-radio-frames}

On its first start, the updated resource imports existing skin artwork and layouts into **Admin > Overlay**. It archives the original `skins` folder after verifying the import. Keep the archive until you have checked your frames in game. If migration fails, the resource keeps the local skins and retries on restart.

Existing frame assignments carry over. Use **FiveM Settings > Permissions and frames > Frame access** to assign new frames by name. Free communities can use imported frames. Editing them or uploading new artwork requires Pro. [Configure frame access](/radio/game-integrations/fivem/in-game-radio/customizing-radio-frames#restrict-frame-access)
