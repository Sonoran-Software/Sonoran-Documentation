Create your community's radio frames in **Customize > Overlay**. The same editor supplies the desktop overlay and FiveM in-game radio.

## Create with Overlay AI {#create-with-overlay-ai}

Use the **AI** tab to create a custom screen and radio frame from a description or reference photos, then refine the design with follow-up messages. You can select **New Frame > Blank canvas** without uploading artwork first. Overlay AI and the Custom screen editor require **Pro**.

See [Overlay AI](/radio/tutorials/usage/desktop-overlay/overlay-ai) for reference photos, chat examples, manual editing, and the monthly AI allowance.

## Create a custom overlay {#create-a-custom-overlay}

Uploading custom frame artwork requires **Pro**.

1. Open your community's **Customize > Game Integration** tab and select your game.
2. Open **Customize > Overlay** and select **New Frame**.
3. Enter a label, choose **Upload image**, and upload your radio artwork. Select **Create**. To begin without artwork, choose **Blank canvas** instead.
4. Open **Manual**, choose a **Screen Theme**, and adjust **Frame Width** as needed. The **Custom** theme adds editable screen colors, typography, icons, and decorative labels.
5. Drag the screen and buttons into place. Use **Add Button** for any missing controls, then select **Save changes**.

*Name your frame and upload its artwork.*

Drag a screen corner to resize it, or hold **Ctrl** while dragging a screen or button. Right-click a button to remove it. Each button action can be added once.

Use **+**, **−**, and **Fit** to zoom the preview. Preview zoom does not change the radio's saved size.

**Reset to game defaults** replaces the full frame set in the editor. Confirm the reset, then select **Save changes** to apply it. Select a game in **Game Integration** first if reset is disabled.

For FiveM frame selection and access restrictions, see [FiveM Radio Frames](/radio/game-integrations/fivem/in-game-radio/customizing-radio-frames).

To configure automatic layout changes and previous/next-frame shortcuts, see [Changing Radio Frames](/radio/tutorials/usage/desktop-overlay/changing-radio-frames), with separate setup for [FiveM](/radio/game-integrations/fivem/in-game-radio/fivem) and [ER:LC](/radio/game-integrations/roblox/erlc-1).

## Use the desktop overlay {#use-the-desktop-overlay}

The desktop app keeps radio controls visible while playing FiveM, Arma 3, Roblox, and other games.

## Open the Overlay {#open-the-overlay}

1. [Download and open the desktop app](/radio/download-the-app).
2. Join your Radio community and connect to a channel.
3. Select the **Overlay** tab at the top, beside **Dispatch**.
4. Position the radio over your game window.



<img src="https://docs-assets.sonoransoftware.com/sha256/67/67c68bf7594dd8339210f64f06560a3f014b21f23ed7ed155ac3b2fb9f9de0bd.png" alt="Sonoran Radio top navigation with the Overlay tab immediately to the right of Dispatch" />

*The Overlay tab is beside Dispatch in the top navigation. Use the desktop app to open it; the website displays it disabled.*



On the website, the tab is disabled; its tooltip explains that the desktop app is required. The mobile app hides the tab.

To return to the main panel, use the radio's power button or **Back to Portal**.

The default ARMA 3 BLUFOR and OPFOR frames use the lower-left button beneath the screen for **Back to Portal**. For a custom frame, open **Customize > Overlay > Manual > Add Button** and add **Back to Portal** for ARMA 3 or **Hide** for other games. Position it over a button, then select **Save changes**.

## Panic and Sonoran CAD {#panic-and-sonoran-cad}

Use the frame's **Panic** button or a custom screen's Panic element to activate or clear your radio panic. To also update your CAD unit, link the CAD community ID, API key, and server ID for your Radio server under **Customize > Dispatch AI > Link Sonoran CAD**. Use the same Sonoran account in Radio and CAD, with your CAD unit on duty.

See [Sonoran CAD Integration](/radio/tutorials/integrations/sonoran-cad-integration#desktop-overlay-panic) for setup and troubleshooting. The CAD API link is required for synchronization; the **Dispatch AI Enabled** toggle can remain off.

## Game Signal {#game-signal}

The overlay displays signal supplied by supported game integrations. For location-based signal, configure [FiveM in-game repeaters](/radio/game-integrations/fivem/in-game-radio/in-game-repeaters), [ER:LC virtual towers](/radio/game-integrations/roblox/erlc-signal-towers), or [Arma 3 signal towers and repeaters](/radio/game-integrations/arma-3/signal-towers-and-repeaters).

## Overlay Controls {#overlay-controls}



<Accordion title="Hotkeys">



1. Open **Settings** > **Hotkeys** on the overlay.
2. Select the button beside **Toggle Desktop Radio** and press your preferred key to hide or show the overlay.
3. Set **Focus Desktop Radio** the same way to interact with the radio while playing in fullscreen.

Set **PTT Hotkey** to your preferred push-to-talk key.

Under **Change Radio Frame**, assign the previous-frame and next-frame shortcuts to cycle through your community's frames. See [Change frames with desktop hotkeys](/radio/tutorials/usage/desktop-overlay/changing-radio-frames#change-frames-with-desktop-hotkeys).



<img src="https://docs-assets.sonoransoftware.com/sha256/9e/9edd16b2c0daabe2f2a016e2c85eb675f166b94b971a40c140b4e345a94ab4ea.jpg" alt="Hotkeys settings showing PTT Hotkey, Focus Desktop Radio, and Toggle Desktop Radio" />

*Example hotkeys; choose keys that do not conflict with your game.*





</Accordion>





<Accordion title="Move or resize the radio">



Drag the radio body to move it. To resize the whole overlay, drag a corner, or hold **Ctrl** while dragging the body: up enlarges and down shrinks.

A brief resize hint appears when the overlay opens and when you hover or focus a resize corner. There is no permanent resize button, and hovering over the radio screen does not repeatedly show the hint.



</Accordion>





<Accordion title="Change the radio frame">



1. Open **Settings** > **Audio** on the overlay.
2. Open **Radio Frame**.
3. Select a frame provided by your community.



<img src="https://docs-assets.sonoransoftware.com/sha256/3e/3eb8bb4238281c7a7b0b62adab69364fcd52292cab2ab411800cdbc46ec1cd1b.jpg" alt="Audio settings with the Radio Frame dropdown open" />

*Select a community frame from the Radio Frame dropdown.*



Arma 3 can select a frame based on your inventory radio. See [Radio Items and Team Frames](/radio/game-integrations/arma-3/radio-items-and-team-frames).

ER:LC can use its visible ELS controller to switch the selected frame between On-foot and Vehicle layouts. See [ER:LC Frame Changes](/radio/game-integrations/roblox/erlc-1) for detection setup and macOS screen permissions.



</Accordion>
