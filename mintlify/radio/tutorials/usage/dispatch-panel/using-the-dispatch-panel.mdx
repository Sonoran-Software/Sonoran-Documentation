### Transmitting (Push to Talk) {#transmitting-push-to-talk}



<Accordion title="Dispatch Push To Talk">



To transmit over Sonoran Radio, you can press the microphone button on the top-left.

Alternatively, use the [PTT hotkey](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#hotkeys-keybinds).



<img src="https://docs-assets.sonoransoftware.com/sha256/3a/3adcb95d39c7ab74c0dfa078e3e07d04062209e776f0dbd82f720a347964794a.png" alt="" />

*Dispatch: PTT Button*



To temporarily transmit in a single channel, and move back to your original channel afterwards, select the keyboard icon to set a per-channel XMIT hotkey.



<img src="https://docs-assets.sonoransoftware.com/sha256/49/4935ea40cdaad0ee368c7e1720557ac401f9dd9d340b09301d334d2a73e8d9a4.png" alt="" />

### Switching Transmit and Scanned Channels {#switching-transmit-and-scanned-channels}



<Accordion title="Switching Transmit and Scanned Channels">



To switch to another channel, click the microphone button on the channel card.

`CTRL` + `Click` on the microphone option to transmit on multiple channels at once.

[You can also change channels via hotkey.](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#hotkeys-keybinds)

<img src="https://docs-assets.sonoransoftware.com/sha256/89/89648bb976e149578ed7683143f6e4d9c4e4362e4eb8c04022fcac8cc384a3de.png" alt="Sonoran Radio - Switch Channel" />

#### Scanning (Listen) To Multiple Channels {#scanning-listen-to-multiple-channels}

Select the headphone icon on each channel to listen in.\

### User Actions {#user-actions}



<Accordion title="User Actions (Right Click)">



Right click in the user to:

* Kick the user from the channel ([Requires Permission](/radio/tutorials/getting-started/invite-and-manage-users#manage-user-permissions))
* Clear the [user's panic status](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#unit-panic)
* Move the user to a different channel ([Requires Permission](/radio/tutorials/getting-started/invite-and-manage-users#manage-user-permissions))
* Adjust the user's volume ([Requires Permission](/radio/tutorials/getting-started/invite-and-manage-users#manage-user-permissions))
* Change the user's display name ([Requires Permission](/radio/tutorials/getting-started/invite-and-manage-users#manage-user-permissions))
* Stun the user from transmissing temporarily ([Requires Permission](/radio/tutorials/getting-started/invite-and-manage-users#manage-user-permissions))
* Ping the user to get their attention

![](https://docs-assets.sonoransoftware.com/sha256/5d/5d0ff91ddda05bd1c29560f1e3a55f07d9bf9aa9c6d2cc8fa4eb4e63ca95693a.png)



</Accordion>



### Unit Panic {#unit-panic}



<Accordion title="Unit Panic Status">



When a [unit toggles their panic status in-game](/radio/game-integrations/fivem/in-game-radio/using-the-in-game-radio#panic), the dispatch portal will reflect this with a red banner and a red highlight on the panicked unit.

Dispatchers can [right-click the user to clear the panic](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#user-actions-right-click) for them.

The [customizable panic sound effect](/radio/tutorials/usage/dispatch-panel/custom-sfx) will also alert dispatchers to an active unit panic.

![](https://docs-assets.sonoransoftware.com/sha256/d5/d59dcfa92756502224da5915c18c0f6b551de71ed891d146eb47b5d49728d1f7.png)



</Accordion>



### Display Names {#display-names}



<Accordion title="Via Dispatch Portal">



To change your display name, users will need the `Change Display Name` permission. To manage others, users will need the `Manage Display Names` permission.

**Via Radio Interface**

Right click a user in the radio interface and select `Display Name`

<img src="https://docs-assets.sonoransoftware.com/sha256/58/58aca092c5cf5cf04c94e2f1af5920cb44249167270ad8d0b1812047c4f3b3f6.png" alt="Sonoran Radio - Change Display Name" />



</Accordion>





<Accordion title="Via Members Tab">



**Via Members Tab**

In the admin panel's `Members` tab, select the drop-down and `Set Display Name` button to edit a user's display name.

<img src="https://docs-assets.sonoransoftware.com/sha256/9f/9f582e60ff0a41e2101fe291683e2fa80679aef7af0ad588462cd43789ec2f86.png" alt="" />



</Accordion>





<Accordion title="Via Sonoran CMS">



**Via Sonoran CMS**

[Sonoran CMS can also automatically set and manage your Radio display names and sync them with Discord.](/radio/tutorials/integrations/sonoran-cms)



</Accordion>





<Accordion title="Via Sonoran CAD Sync">



[Learn about automatically setting radio display names to match your unit information in Sonoran CAD.](/radio/tutorials/integrations/sonoran-cad-integration)



</Accordion>





<Accordion title="Via Command">



Use the in-game command `/radio displayname John Doe` to update your radio display name.

[In-game commands can also be restircted with ACE permission](/radio/game-integrations/fivem/in-game-radio/configuring-ace-permissions)s.



</Accordion>





<Accordion title="Via Developer Export or Endpoint">



Programmatically [update a user's display name in FiveM](/radio/developer-documentation/developer-documentation/resource-events#set-display-name), [update a display name via API](/radio/developer-documentation/developer-documentation/api-endpoints/users/set-user-display-name), or use a [custom framework function for guest users](/radio/developer-documentation/developer-documentation/resource-events#guest-display-names).



</Accordion>



### Volume Changes {#volume-changes}



<Accordion title="Volume Sliders">



Adjust the overall voice and sound effect volume by [opening the settings menu](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#dispatch-hotkeys) and selecting the `Audio` tab.

In addition to the manual sliders, you can customize how much the [volume hotkeys](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#dispatch-hotkeys) adjust the volume.

You can also [adjust volume for a specific user](/radio/tutorials/usage/dispatch-panel/using-the-dispatch-panel#user-actions-right-click).

![](https://docs-assets.sonoransoftware.com/sha256/12/12483a1ea4ad514a4748348b031c45ce4cb1a3f52d6a9e075a14856f2332f061.png)



</Accordion>





<Accordion title="Per-User Volume">



Right-click on a user to individually increase or decrease their transmission volume.



<img src="https://docs-assets.sonoransoftware.com/sha256/4f/4f57024a4deb46c1607a11b67721c183452628d5c180e19bd890a48513ac5c89.png" alt="" />
