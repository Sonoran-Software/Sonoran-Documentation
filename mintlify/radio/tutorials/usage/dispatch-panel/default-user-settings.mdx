## Default User Settings {#default-user-settings}

The radio settings menu offers vast preference options for sound effects, text-to-speech, automatic gain control, and more. Some communities may wish to enable or disable specific settings for users by default.

### Setting Defaults {#setting-defaults}

In the Admin panel, select `Customization` > `Default Settings`

Here you can enable, disable, and configure default settings for all users in your community.

### Users: Reset to Default {#users-reset-to-default}

Users can still customize their own setting preferences by selecting the gear icon in the dispatch or radio view to override the community defaults.

Under the `Advanced` tab, users can select `Reset Settings` to reset to the community defined defaults.

## FiveM Default Settings {#fivem-default-settings}

If you’re using a release that predates **FiveM Settings**, see the [previous guide](https://github.com/Sonoran-Software/Sonoran-Documentation/blob/8c017dc2fe962a3b750d4b34bb53aa0fb72bcb54/mintlify/radio/tutorials/usage/dispatch-panel/default-user-settings.mdx).

In **Admin > Game Integration > FiveM Settings**, select the **Radio Server** whose defaults you want to change.

### Keybinds {#keybinds}

Expand **Default keybinds** and set the controls you want to change, such as **Push to talk** or **Toggle auto callouts**.

### ESC Behavior {#esc-behavior}

In **Radio > Radio and audio**, set **Escape key behavior**. [Restart the resource after the settings save.](/radio/game-integrations/fivem/installing-the-in-game-resource#configuration-values)
