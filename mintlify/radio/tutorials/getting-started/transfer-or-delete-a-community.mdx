## Transferring a Community {#transferring-a-community}

### 1. Select the New Owner {#id-1.-select-the-new-owner}

Open **Admin > Info**. Under **Danger Zone**, select **Transfer Community**.

Choose the new owner and type the confirmation text shown in the dialog.

After selecting the new owner, a confirmation email will be sent. Check your inbox to complete the transfer.

## Delete Community {#delete-community}

Open **Admin > Info**. Under **Danger Zone**, select **Delete Community**.

_Note: Only the community owner can delete the community._

After confirming deletion, a **Deleting community…** loading state appears. Wait for completion rather than repeatedly submitting. Successful deletion returns you to the Portal; communities using a custom domain return to the main Sonoran Radio Portal. If deletion fails, an error is shown instead.
