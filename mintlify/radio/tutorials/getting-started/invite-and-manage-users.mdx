## Automatic Join, Kick, Ban, and Permission Sync {#automatic-join-kick-ban-and-permission-sync}

Sonoran CMS allows you to automatically add and manage user permissions with user applications, sync them with Discord roles, and more!



<Card title="[sonoran-cms.md](../integrations/sonoran-cms.md)" href="/radio/tutorials/integrations/sonoran-cms" />



If you are building your own integration, Sonoran Radio also exposes API endpoints to approve members, kick members, ban members, update member display names, and set member permissions.



<Card title="[users](../../developer-documentation/developer-documentation/api-endpoints/users/)" href="/radio/developer-documentation/developer-documentation/api-endpoints/users" />

## Discord Role Sync {#discord-role-sync}

Choose Discord role permissions in **Customize > Discord**, or select **Set up role sync** in **Members**.

## Manual User Management {#manual-user-management}

### Inviting Members {#inviting-members}

Users will need the `Community ID` located in the `Administrator` panel.\
Communities can also [customize this community ID](/radio/tutorials/usage/dispatch-panel/custom-domain-vanity-url#vanity-urls).



<img src="https://docs-assets.sonoransoftware.com/sha256/e3/e32cc090d9c8f71b9a810bda77b6ee1895f146e8b86d67ff62b8e98312487b7a.png" alt="" width="375" />

*Sonoran Radio: Community ID*



When logged into Sonoran Radio, they can select the `+` button in the portal to paste in the `Community ID`.



<img src="https://docs-assets.sonoransoftware.com/sha256/63/63fd4b6db1c4a79956d72931236b1428c5999d0eb279148ec74dc984084a8e13.png" alt="" width="170" />

*Sonoran Radio: Join Community*



### Approving Members {#approving-members}

When a member joins your community with an invite code, they will be pending until approved.

Users with the `Approve Pending Members` permission can approve in the `Members` tab



<img src="https://docs-assets.sonoransoftware.com/sha256/d3/d3def2acc4a629fdd4df3efc624c1856b15e086b9b1a340129f77172ec98de22.png" alt="" width="375" />

*Sonoran Radio - Approve Members*



### Manage User Permissions {#manage-user-permissions}

User permissions can be manually set by clicking the shield icon on a user in the `Members` tab



<img src="https://docs-assets.sonoransoftware.com/sha256/81/81aef0a71783fb1f77fa4a2c2341fa19666537ffe0f9746f33fc2cccfc5c6739.png" alt="" width="284" />
