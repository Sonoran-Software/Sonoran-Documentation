# Configure a Game Integration

Community registration and channel setup are shared across games. Follow the installation guide for your game:

## FiveM

Open **Customize** > **Game Integration** > **FiveM**, then follow [Installing the FiveM In-Game Resource](installing-the-in-game-resource.md).

## ER:LC

Open **Customize** > **Game Integration** > **ER:LC**, then follow [ER:LC Setup](../game-integrations/roblox/erlc-setup.md) to link your private server and Roblox account.

## Arma 3

Follow [Arma 3 — Install and Connect](../integrations/arma-3/install-and-connect.md). Arma uses its own mod and the desktop overlay; it is not a selection in the Game Integration panel.

## Other Games

Use the [desktop app and overlay](../usage/desktop-overlay.md) for radio controls while playing.
