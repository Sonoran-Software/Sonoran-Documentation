# Game Integrations

Choose your game for installation and game-specific features.

| Game | Setup | Radio controls |
| --- | --- | --- |
| [FiveM](fivem/) | Install the FiveM resource. | In-game radio |
| [Roblox / ER:LC](roblox/) | Link your ER:LC private server and Roblox account. | Desktop app and overlay |
| [Arma 3](../integrations/arma-3/) | Install the Arma mod on the server and player computers. | Desktop app and overlay |

**[Star Citizen](star-citizen/):** Coming soon.

For other games, use the [desktop app and overlay](../usage/desktop-overlay.md). Game-specific signal features require a supported integration.

Community setup, channels, and dispatch controls are covered in [Getting Started](../getting-started/) and [Using Sonoran Radio](../usage/).
