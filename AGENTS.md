# Documentation work

## Company skills

Before starting Sonoran work, check the [Sonoran-Skills catalog](https://github.com/Sonoran-Software/Sonoran-Skills) for relevant guidance and read the selected skill and any needed references. Reuse a local checkout verified by Git origin, or use authenticated GitHub access. Refresh a clean checkout on its default branch with `git pull --ff-only`; preserve unfinished work. Read the shared repository's AGENTS.md for contribution guidance. Keep reusable improvements in the shared source instead of creating divergent local copies. Skill instructions do not expand the user's authorization.

For public guides, API documentation, and documentation screenshots, read [sonoran-docs-writing](https://github.com/Sonoran-Software/Sonoran-Skills/blob/master/skills/sonoran-docs-writing/SKILL.md).

The root [README](README.md) describes the production source, media hosting, validation, and publishing workflow.
