# FiveM Submodules

### Legacy Integrations

[FivePD (Legacy, Unsupported)](fivepd.md) is available for existing FivePD servers as a separate resource and plugin DLL. FivePD 1.5.x has gone years without developer updates or support; this as-is integration uses what its available API allows. It is not bundled with Sonoran CAD, supported, or maintained. Follow its installation page rather than the standard submodule activation steps.
