# FiveM Submodules

### Legacy Integrations

[FivePD (Legacy, Unsupported)](fivepd.md) is available for existing FivePD servers as a separate resource and plugin DLL. It is not bundled with Sonoran CAD, supported, or maintained. Follow its installation page rather than the standard submodule activation steps.
