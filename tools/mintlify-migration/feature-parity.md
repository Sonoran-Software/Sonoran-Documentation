# Public feature parity

Reviewed 2026-10-19 (America/Phoenix). Public staging preserves the published documentation and ordinary search. It does not reproduce every paid GitBook service or import cloud-only collaboration records. Production DNS and GitBook cancellation remain separate decisions.

## Observed publishing and integrations

Public HTML was inspected for the [live home](https://docs.sonoransoftware.com/), [CAD](https://docs.sonoransoftware.com/cad), [CMS](https://docs.sonoransoftware.com/cms), [Radio](https://docs.sonoransoftware.com/radio), and a [representative endpoint](https://docs.sonoransoftware.com/cad/api-integration/api-endpoints-v2/general/accounts/get-account), then compared with [Mintlify staging](https://sonoran-software-systems.mintlify.app/), its configuration, and the exported source.

| Feature | Observed result |
| --- | --- |
| Tracking and widgets | Sampled GitBook script URLs and external stylesheets use its own `static-2v.gitbook.com` host. No GA4, GTM, Universal Analytics IDs, common third-party analytics loaders, or chat-widget scripts were found, including escaped inline payloads. GitBook's own Insights/link-click instrumentation is present. Staging has no configured owner analytics integration or GA/GTM ID. No new tracking was added. The live site’s Installed Integrations UI also explicitly reported no installed integrations. Consent-dependent runtime loading was not exercised. |
| Navigation and branding | Product navigation, official logos/favicon, links and headings have migration checks. GitBook's footer exposes support, Discord, X, Instagram, YouTube and legal links. These footer links were restored and browser-checked after deployment. Its inherited Terms of Service footer incorrectly pointed at Refund/Purchase Policy; the verified `/policy/policy/terms-of-service` route now repairs that navigation, without changing legal text. Mintlify's vendor attribution remains on the free site. |
| Pages and URLs | All 914 HTML/Markdown GET and HEAD checks passed, as did 58 redirect rules. Sitemap and recursive agent indexes cover the 913 intended indexed pages; one legacy adapter is intentionally excluded. Staging HTML and Markdown carry noindex directives while agent retrieval remains available. The same production domain can be connected after cutover checks; existing links are preserved through pages or redirects. See [hosted evidence](evidence/hosted-verification.json). |
| Content and downloads | Tabs, callouts, code, tables, captions and media were converted. All 2,425 visible fenced-code payloads passed fidelity checks. Media and linked downloads use the independent asset host; 2,875 stored objects were compared against source metadata. This avoids relying on GitBook file hosting or Mintlify's restrictions on larger files and certain downloadable types. See [content evidence](evidence/content-fidelity.json), [media evidence](evidence/media-verification.json), and [Mintlify's file rules](https://www.mintlify.com/docs/help-center/static-file-not-served). |
| API documentation | Exported endpoint pages contain authored SDK/OpenAPI example tabs. The sampled live endpoint had no observed interactive request playground; staging has zero generated OpenAPI endpoint pages. Starter supports a playground, but adding an interactive one would require deliberate API-spec configuration and testing. The organization OpenAPI UI showed an empty specification setup, so no separately configured specifications were observed. [Migration guide](https://www.mintlify.com/docs/migration/gitbook). |
| Search and integrations | Native public MCP search and direct Markdown/file retrieval passed. Their tool names and response contracts differ from GitBook's MCP/API. Keeping page URLs does not keep those vendor APIs compatible; support-tool adapters need separate acceptance. Agent indexes must follow their advertised child URLs: the `.site` alias briefly served a stale child-index cache while the advertised `.app` URL was fresh. [MCP documentation](https://www.mintlify.com/docs/ai/model-context-protocol), [agent indexes](https://www.mintlify.com/docs/ai/llmstxt). |

## Free-plan differences and records to retain

Starter includes five editor seats, Git sync, a custom domain, search, MCP, custom CSS/JS and the API playground. Reader Assistant, writing agent, platform/agent analytics, preview deployments and developer/admin APIs are paid features. Native PDF export, white labeling and role-based personalization require Enterprise. Built-in metrics, search history and prior feedback are not transferred into a new analytics dashboard. [Current plan comparison](https://www.mintlify.com/pricing).

The live GitBook home exposes an Assistant, and recent usage is present in the private site analytics. The free preview intentionally uses ordinary search instead. The Mintlify Assistant dashboard was set Inactive; hiding remaining trial controls with CSS does not cancel a trial or independently disable a backend service. The account still reports a trial end date. [Assistant configuration](https://www.mintlify.com/docs/assistant/configure).

The existing restricted Support section requires a separate protected destination or an appropriate authentication plan. It is excluded from public staging. Starter's Mintlify-member authentication does not establish parity with the existing visitor-role access rules. [Authentication plan comparison](https://www.mintlify.com/pricing).

Git history remains available in the repository. GitBook-native revisions, comments, reviews and unmerged drafts are separate records; this conversion does not make them Mintlify history or publish those drafts. Private draft-review snapshots retain visible text and media references; they do not fully export binaries, comments or history. Preserve needed cloud records and review pending changes before ending GitBook access. The official migration guidance likewise distinguishes source exports from private sections, unpublished changes, permissions, comments and revision history. [GitBook migration guidance](https://www.mintlify.com/docs/migration/gitbook).

This report covers the currently published site. Legacy/unpublished organization content is a separate private retention scope. Any later subscription change concerns the paid site plan; organization/account deletion is outside this migration.
